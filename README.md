# Qwen3-ASR 本地语音工作台

本项目包含浏览器界面、Mac 上的 FastAPI 服务，以及可选的远程推理节点（`ai-infer-node/`）。工作台、课程页和任务 API 共用一个进程和端口，默认是 `127.0.0.1:8765`；课程服务挂载在 `/course`，不再单独启动 8766 后台。

面向 Apple Silicon Mac 的本地实时语音转写网页。ASR 使用 `mlx-community/Qwen3-ASR-1.7B-bf16`：由官方 Qwen3-ASR-1.7B 转换而来的完整 BF16 权重，不做 8-bit/4-bit 量化，并通过 MLX 使用 Apple Silicon GPU。浏览器将麦克风重采样到 16 kHz 后发送给 Mac 服务，Mac 保存可恢复音频、处理分段并归档。ASR 选择本地模式时由 Mac 推理；选择远程模式时，音频片段会发送到已配置的 Windows／Linux 节点，返回转写结果。可选的 AI 修正、整理、总结和中英互译通过 OpenAI Responses API、Chat Completions API 或兼容的本地 `/v1/responses`、`/v1/chat/completions` 服务完成；五个 AI 功能各自使用独立配置。

所有页面共用浏览器主题按钮。首次打开时跟随系统的浅色 / 深色偏好，手动切换后保存在当前浏览器的 Local Storage；主题只改变界面颜色，不会修改录音、课程资料或 AI 配置。

## 课程知识与智能课堂

主版本提供课程知识库、带时间锚点的速记增强、相关资料侧栏和分范围课堂问答。课程资料仅索引已经完成的 MinerU 转换 PDF，复用逐页转写与来源页码；课堂定稿转录、手记和术语共同检索，新增资料自动增量更新。默认本机模型为 `Qwen3-Embedding-0.6B`，查询与资料使用相同模型契约；生成继续使用各功能保存的云模型配置。原始 ASR、纠错提议和增强笔记分别保存，人工编辑受到版本保护。

日常启动沿用 `start_qwen_asr.command`，也可使用 `启动智能课堂新版.command`。课堂版将硬件选择保存在独立配置中，初始使用 Mac；原有 Windows 节点和任务回执继续保留。配置、依赖与模型准备、数据备份及恢复见 [智能课堂使用说明](docs/智能课堂-使用与恢复.md)，实测结果及未验证项见 [智能课堂验收记录](docs/智能课堂-验收与模型实测.md)。

## 页面入口与课堂记录

启动后顶部提供课程工作区（`/workspace?category=课程名`）和五个兼容入口：**录音工作台**、**课堂记录**、**课程回放**、**PDF 资料库**、**任务中心**。课程资料按课程、文件名与类型查看；生成的课堂笔记 PDF 留在对应课堂，打开笔记即可下载，不另存进课程资料列表。原 `/notes` 地址自动跳转并保留课程参数。课堂记录现在是独立页面，支持按标题、逐字稿和课堂笔记全文搜索；打开录音后可以点击时间戳回听，并从笔记中的“原文 S1”链接定位到对应片段。笔记在重新生成、手动修改或从 IdeaShell 拉取前会自动保留历史版本，可在“版本历史”中比较和恢复。

上传录音会先进入后台任务，关闭网页后仍会继续处理；任务中心可以查看、暂停、继续或取消上传转写。AI Key 会按接口地址保存，切换 Base URL 后不会把旧服务的密钥发送给新服务。各 AI 功能保留自己的并发上限；同一 API 账号／当前服务用户的 AGY CLI 账户还共享总并发上限，默认 4，可通过 `QWEN_ASR_AI_TOTAL_CONCURRENCY` 调整。功能分别设为 2 路和 3 路时，账户合计仍最多 4 路。调整限额复用同一个计数器；降低限额不取消已进入的工作，后续请求等待运行数降到新限额以下。

本轮修复、测试与清理范围见 [稳定性修复验收](docs/2026-10-13稳定性修复验收.md)。需要独立预览时，可运行 `.venv/bin/python scripts/preview_workspace.py --port 8876`；预览使用项目内独立的 `.workspace-preview/` 数据目录，不加载正式 `.env`。

代码审查修复、空闲模型释放、CPU／内存对照及上机步骤见 [审查修复与空闲资源验收](docs/review-fixes-idle-resources.md)。运行 `python3 scripts/sample_idle_resources.py --seconds 60` 可观测已启动工作台的 CPU 与模型子进程 RSS。

## 最简单的启动方式

双击 `start_qwen_asr.command`。脚本读取持久化推理配置并检查相应依赖，启动一个后台服务后打开浏览器。仅远程 ASR 使用不含 MLX 的核心依赖，不要求 Mac 本地模型；启动不会下载权重。本地模型在明确准备后、实际转写时加载。关闭终端不会停止服务。双击 `stop_qwen_asr.command` 可安全停止；仍有录音、下载、转写或 AI 任务时会拒绝退出，提示先在页面处理。

打开网页后先填写录音名称并选择或新建分类，再点击“新建并开始转写”。首次使用时允许麦克风权限。说话过程中会滚动显示识别文本，短暂停顿后生成正式段落。

- 每条活动录音只有一个音频写入连接。第二个页面可以查看状态；尝试开始时会提示是否接管。确认接管后旧页面停止收音，旧数据包和旧连接断开不会影响新连接。当前写入连接断开后，下一次开始可恢复同一会话及待转写片段。
- 主按钮只负责开始、暂停和恢复收音。暂停会立即停止收音并恢复按钮，剩余 ASR 和 AI 处理在后台完成；连接确认超时或断开也能恢复操作，无需刷新。
- “结束并保存”先停止收音并等待已接收片段的 ASR，完整保存 AAC、`原始转写.txt`、`AI修正后文本.txt` 和 JSON，归档完成后再提交“课后复习笔记”任务，生成详细课堂笔记与短摘要，新增 `AI总结.md`。没有 AI 设置、设置损坏或总结服务失败时，音频和已有转写仍可保存；总结任务会明确显示失败原因，可在修复设置后重试。结束时尚未完成的实时校对／提纲会暂停并保留可继续状态，不阻塞音频保存。ZIP 只在点击下载时临时生成，传输结束或中断后自动删除，不留在录音文件夹。与录音中的“课堂实时提纲”开关独立。
- 结束保存和 AI 笔记生成由后台任务执行，刷新或关闭网页不会取消已提交的任务。重开页面会恢复进度；若本地 Python 服务也被关闭，重启后会将未完成任务标为可重试。录音恢复会补转写磁盘中已保存但尚未识别的片段；AI 生成保留成功分块及原有笔记，可以重新生成，也可以单独重试短摘要。服务停止期间不会继续采音或调用 AI。
- 每次新会话都会立刻在资料库根目录的 `<分类>/<录音名称>__<编号>/` 中建立完整档案。可在网页“全部设置 → 资料库与设备”中选择资料库文件夹；点击“迁移并保存”后，现有录音和课程配置会迁移到新位置，目标目录里的其他文件不会移动。录音进行中或上传转写处理中不能迁移。录音进行中使用隐藏的可恢复 WAV 底稿，结束时转成单声道 16 kHz / 64 kbps AAC。
- 关闭网页、关闭浏览器或重启服务都不会把会话标记为结束。再次打开网页会恢复原会话和已有转写；受浏览器安全限制，关闭网页期间无法继续采集麦克风，重开后点击“恢复转写”即可继续。
- “上传录音一键转写”支持一次选择多个常见音频/视频文件。弹窗实时显示当前原始转写、AI 修正/翻译和总进度；文件 ASR 与远端 转写校对重叠运行，精修、长文本整理和全局改写都按配置使用 1–8 路有界并发，完成后仍按原始时间顺序归档。处理后统一归档为 AAC，并提供按需生成、下载后自动清理的完整 ZIP。
- AI 修正和翻译可以在实时录音中随时切换。正在说的一句话继续使用原设置，停顿定稿后，下一句话使用新设置。仅在启用相应功能时才校验对应 AI 配置；关闭 AI 时不会强制验证无关提供商。
- 开启 AI 修正时，程序除逐句低延迟校对外，还会在每完成 5 分钟内容后进行一次整体复核。整体复核会结合上一窗口的末尾上下文，修复跨段断句、合并可连接的碎片段并重新组织自然段；页面以“AI 整体整理”卡片替换对应的小段，原始小段仍可展开查看。
- 开启“课堂实时提纲”后，录音过程中会按自定义间隔维护累计课堂总结，并使用独立的“分段整理”提供商。课后详细笔记使用独立的“课后复习笔记”提供商，录音结束后自动生成，也可在课堂记录重新生成；上传转写完成后可手动生成。“长文本复核”提供商只负责上传文件的全局长文本整理。五个功能页分别保存 API 或 AGY CLI 通道、模型、Key、Context Window、接口格式、自定义参数、提示词和并发上限；默认课后复习笔记 3 路，其余功能 2 路。AGY 通道使用本机 `agy`：短请求经 `stream-json` 传递，长请求使用分块资料文件，并在系统沙箱内读取；程序核对全部文件、行范围与哈希，避免 CLI 的单条消息限制静默截断资料。AGY 1.4 返回空正文时，只恢复本次会话中输入一致、工具读取成功且完整结束的最终正文；失败步骤或思考文本不会作为结果。显式重试可开启一轮有上限的知识清单修复，旧提案与已完成批次保留。知识清单或正文实际达到上游输出上限时，按完整来源／知识组递归拆分并保存每组检查点；续写断线不会掩盖先前的输出截断原因。长文本不会放入命令行参数；Gemini Flash 的 `-low`/`-medium`/`-high` 版本直接在模型名中选择，`-high` 可使用 high 思考强度。
- 工作台转写区右侧的“课堂问答”占内容区约 1/3 宽度，默认使用 AGY `gemini-3.8-flash-high`。每次提问从服务端重新读取这节课截至此刻的完整转写，优先使用精修文本，携带真实时间戳，并可附加课程背景、术语、最新总结、此前问答和未定稿的滚动预览。回答默认先给一句结论和 2–4 个短要点，支持 Markdown、表格、代码及 KaTeX 公式。顶部模型下拉框从本机 AGY 读取可用模型，切换后保存到本机；“全部设置 → 课堂问答”可修改通道、模型、窗口、输出预算、提示词和附加内容。完整转写与当前问题始终发送，超出窗口时明确提示，绝不静默截断课堂前文。尚未识别的语音无法作为文本上下文，界面会标明转写进度。问答单独保存到每条录音的 `classroom-chat.json`，支持刷新恢复、追问、复制、失败重试及清空问答。
- 详细笔记优先将完整转写一次交给 AI，结合全文建立上下文联系。只有全文、实际提示词、JSON 编码开销及预留输出空间超过配置的 Context Window 时才分块；不再固定切成约 3,000 token。全文生成结果直接保存；超限分块仍保留按时间排序和失败重试能力。AGY Gemini 的详细笔记优先全文请求，不再沿用 API 提供商按输出 token 比例预先切片的策略；全局校对与补齐精修也使用更大的连续段落组，同时保留逐字输出规模、来源映射和实际错误后的拆分保护。请填写对应服务实际支持的窗口；模型输出截断时明确报错，旧笔记保留。
- 图文笔记的逐页审查发现问题后，后台会自动对照实际页面、课件原图和课堂原文，区分真实错误、误报与合理续页。AGY 只提交相关知识块的精确局部补丁；程序校验知识清单、学习深度、来源与原图绑定，再重新编译并由另一个会话审查。阻断意见存在争议时保留原报告，重新分配争议页面给新会话，不由修正者直接宣布通过。每轮最多两次修订、每个问题页最多三次提案，网络中断与重启保留检查点；证据不足或达到上限时保留完整诊断和继续入口。PDF 升级可自动修正排版稿，已保存的正文受到保护。
- “AI 任务”页集中显示课后总结、实时累计总结和未精修内容；失败或未完成的录音会自动出现在这里，并提供“全部继续、全部暂停、全部重试”和“一键重试失败任务”。临时 429 限流、网络中断或 502/503/504 服务繁忙会按 15–300 秒退避并自动恢复（最多 6 次）；余额或总额度耗尽会停止自动循环并明确提示。输出截断、请求片段过长、JSON 损坏或段落映射异常会缩小连续分块后重试；已经成功的进度保留。同一时间窗口的旧版重复失败记录聚合为一项。

右侧“课堂记录”支持分类筛选、月历热力图和按日期查看。每条录音可在完成后生成课后复习笔记，再根据总结和可配置提示词生成标题。点击“AI 取名”后直接保存新名称，无需再点击“保存名称与分类”。点击“查看笔记”会进入全屏左右分栏：左侧为逐字稿，右侧默认完整渲染 Markdown（标题、列表、表格、代码块、行内/块公式）。生成提示词强制数学内容使用 `$...$` 或 `$$...$$`；若兼容模型仍把明显公式写成单反引号代码，阅读与保存链路会将其规范为行内公式，同时保留真正的程序代码。点击某一段只编辑该段，其余内容继续阅读；编辑后约 0.9 秒自动保存，失焦或关闭笔记时立即保存，Esc 撤销当前段，⌘/Ctrl+Enter 完成。保存请求按顺序执行，返回时不重绘编辑区；网络失败会保留本机草稿，恢复页面后继续保存。与其他页面或任务发生内容冲突时保留草稿并提示核对。阅读器提供目录、展开阅读和 Markdown 源码入口，保存后重新打开仍保持原格式。也可以重新命名、移动分类、下载或删除；删除会把整条录音目录移到系统废纸篓。

完成后的课后复习笔记可手动同步到 IdeaShell。首次在高级设置中点击“连接 IdeaShell”会打开 OAuth 授权页面，令牌与客户端注册信息以仅当前用户可读的方式保存在 `~/.qwenasr/`。点击推送后先展示实际内容预览，可选择“总结＋精修原文”“仅总结”或“仅精修原文”；默认是一条完整归档，上半部分 课后复习笔记、下半部分带真实时间戳的精修录音原文，并自动附带当前录音文件。录音附件按闪念贝壳实时 MCP schema 上传，单个录音超过 25 MB 时，优先无损拆成上半段和下半段；两段仍过大时按需压缩。两个文件按顺序附到同一篇完整笔记，正文保持完整，预览展示一篇正文与全部附件。新建请求发送前会持久化操作编号、目标文件夹和内容／附件摘要。响应丢失、超时、取消或未返回 ID 时进入“结果未知”，普通重试不会再次新建。协议没有已验证的幂等创建／可靠自动对账能力，因此需要在 IdeaShell 查找条目，将 ID 填入预览中的“核对并关联”；服务端只读取正文，校验发送时内容摘要一致后关联。内容不同则保留未知状态，不覆盖远端。确实需要另一篇时单独选择“明确新建另一篇”，原操作记录仍保留。目标笔记可选择普通推送或明确新建；已关联条目不在课程文件夹中时会先阻止更新，提示检查已删除或移走的关联；闪念贝壳会保存录音，但不会自动转写，需在 App 内手动发起转写。尚未精修的片段会明确标注并保留原始识别内容，不会伪造时间戳。全屏笔记右上角可从已关联的 IdeaShell 条目拉取 Markdown，拉取时只提取旧归档中的“AI 总结”章节，避免把原文重复塞入总结。开发验证请使用模拟接口，不要创建真实测试笔记。

图文笔记推送会读取本机配图的实际文件，以每批最多 9 张追加到同一篇笔记。图片缺失或超过单图 5 MB 时会阻止推送；预览后图片或 PDF 发生变化也必须重新预览。IdeaShell 图片是笔记级附件，正文使用配图编号和附件名对应，不再发送无法在远端打开的本机相对路径；已有当前版本的已导出 PDF 时会同时附带，以保留原图文排版。中途失败保留笔记 ID 与已上传数量，重试更新同一篇笔记，服务端按文件字节去重。从 IdeaShell 拉取时会还原本机图片引用。

国内 IdeaShell MCP 已迁移到 `https://mcp.ideashell.cn/mcp`，兼容已有授权、旧笔记关联和附件去重。服务端目前的新授权限制，以及实测的文档格式、大小和自动文本提取能力，见 [IdeaShell MCP 迁移与附件能力](docs/IdeaShell-MCP迁移与附件能力.md)。

批量转写会将音频在约 90 秒处寻找静音位置切段，并把课程中的 `max_tokens` 当作上限，根据实际片段时长自动缩小。检测到异常重复输出时，长片段会自动二分重转；较短片段会裁去循环尾。单段超过 180 秒会终止，任务保留为“可继续”。服务或网页中断后，可以在课堂记录点击“继续处理”，从最后成功的音频时间点恢复。逐段 AI 结果会立即持久化；全局改写按 Context Window 安全分块并发处理，局部失败时保留已完成分块，下次只重试缺失部分。

课程回放和上传录音使用 AGY Gemini 校对且未开启翻译时，按保存的上下文和输出预算合并，每批最多累计约 30 分钟或 24,000 个估算正文 token，结束时提交尾批。已有完整转写的补校对不再按并发数缩小批次；相关前后文以约 40% 输入窗口为目标，并检索本批前、中、后内容对应的课程背景，资料不足时不填充无关内容。每份通过编号校验的结果立即落盘，自动拆批时已成功的半批也独立保存。取消、暂停或其他批次失败不清除成功结果，继续与普通重试只补未完成部分。数字、公式的待核对候选属于已计算结果，不重复调用 AI。明确重新生成前保存旧版本。任务中心按已保存段落显示进度，阶段完成不代表整份笔记完成。

## 南邮课程回放转写

双击 `start_qwen_asr.command`，或从语音工作台点击“课程回放转写”，进入 <http://127.0.0.1:8765/course/>（可通过 `QWEN_ASR_PORT` 修改端口）。语音工作台和课程回放由同一个本地服务提供，不再启动第二个端口。首次在本机页面填写统一身份认证账号密码；勾选保存后，以后启动程序会自行登录。账号配置只保存在 `~/.qwenasr/smartclass/credentials.json`（0600），不会读取浏览器 Cookie，也不会把密码发给 AI 服务。

选择本学期课程，再勾选需要获取的课次并点击“将选中课次加入队列”。运行期间仍可切换课程、刷新回放并继续追加课次，重复提交正在排队或执行的课次不会重置任务。程序仅处理选中课次，不检查漏录、不自动补历史课程。同一天同课程、教师一致、节次相邻且间隔不超过 10 分钟的两节回放会组成一堂课，标题取自回放标题中的课程名称。未配对的单节默认不可选，可明确开启单节获取。

课次列表按学校回放编号匹配本机课堂记录，已完成的课次显示“已入库”；两节中只有一节完成时显示“部分入库”，并列出各节状态。已提交的任务显示“已排队”“入库中”“已暂停”或“待继续”，状态会自动更新，刷新浏览器和重启服务后仍保留。改过录音标题也能匹配；删除录音后不会继续标为当前已入库。

右侧运行状态只显示正在执行和排队的课次，完成后自动移除；历史结果在课堂记录和任务中心查看。队列最多同时推进三个课次，其中两个下载通道可以重叠工作；下载结束就释放通道供后续课次使用，转写和笔记可继续在后台处理。本地 ASR 仍由现有模型调度器串行推理。同一回放来源的单节和合并课次会依次处理，避免同时写入一条录音。

每条课次右侧提供“上半节回放”“下半节回放”，未配对的课次提供一个“课程回放”按钮。尚未入库也可使用，从对应半节课的开头打开；点击回放不会勾选课次或触发入库。所有回放链接只开一个新标签页，在其中自动登录并定位，不再留下中转页面；需将已有油猴跳转脚本更新到 1.2.0，见 [油猴脚本说明](docs/SmartClass油猴回放跳转.md)。新版脚本也支持直接打开 Smart Class 时自动登录并返回原页面。回放页进入时核验登录、自动恢复已保存账号，并从教学班和“与我相关”的本学期视频动态更新课程列表，包括没有主讲或教学班信息的回放。

课程回放的录音日期、时间、日历归属和排序使用 SmartClass 平台的上课时间，两节合并时取第一节开始和最后一节结束时间（北京时间）。`started_at`、`recorded_at` 记录上课开始，`ended_at` 记录已确认的平台结束时间；本地导入与归档时间分别保留在 `imported_at`、`archived_at`。旧课程可从来源记录恢复正确时间，普通录音和文件上传仍使用原有日期规则。

现在使用分段流水线：支持 HTTP Range 的媒体通过四个下载线程读取 8 MiB 分段，先获取 1 MiB 供解码器尽早读取，临时视频缓存使用磁盘并在结束或暂停后释放；不支持 Range 时沿用普通读取。从 `video1` 解码音轨，在约一分钟附近的低音量处切段；一段下载完成就立即交给当前配置的本地或远程 ASR，识别出的文字同时交给已配置的 转写校对。页面分别显示下载分钟数、转写分钟数、精修段数。两节课保持一个录音条目和连续时间戳，收齐后归档成一个 AAC、逐字稿、精修文本和一份 AI 课堂笔记。整堂课笔记在全部转写完成后生成。下载、转写、精修相互重叠，但本地模型与 AI 服务本身的处理时间仍会影响总耗时。

“笔记设置”可分别调整精修和总结模型，或关闭任一功能。修改后自动保存到 `~/.qwenasr/smartclass/options.json`，也可点击“保存笔记设置”。实际请求的提供商、模型与提示词始终从服务端持久化 AI 设置重建；课程队列保存自己的操作开关与来源信息，不能用历史网页提供商配置覆盖当前设置。密钥复用主工作台按接口绑定的本机密钥库。

选中的课次和提交时的设置会保存在本机队列。重启并登录成功后，只继续已经提交且没有主动暂停的课次。点击“暂停队列”后保持暂停，可用“继续已保存队列”恢复；不会查找漏录或自动新增课次。网络失败的项目保留进度，可手动继续。

重复提交课次或音频段会校验并去重。每个分段有落盘检查点，可恢复音频保存后、主记录写入前的中断。未完成分段放在 `.course-chunks/`；归档后清理分段，并保留 `.course-source.flac` 无损底稿供后续补课。先导入 A、后来选择 A+B 时，复用本地 A，只获取 B，保留已有标题和人工修改，补齐前在 `.versions/` 留一份备份。旧版没有无损底稿时复用已有 AAC；源顺序或归属冲突会提示核对。

实时定稿优先于滚动预览和后台 ASR；后台等待过久仍有执行机会。当前 GPU 推理完成后才能让出，出现实时请求时后续后台块缩短到最多 25 秒。精修缓冲上限为 512 个已保存文本段，不缓存音频；达到上限后才等待，AI 失败时原文保留。每堂课上限为 2 小时。课程页面显示首段文字耗时和 ASR 排队/推理耗时；`/api/health` 提供当前进程最近 500 次请求的 p50/p95 统计。

学校平台与视频服务器的网络可达性不同。网络切换后，程序会重新建立认证连接，对读取请求和视频读取最多重试 3 次；密码提交只尝试一次。失败信息显示具体步骤、服务器与超时/解析/连接类型。2026-09-10 在宿舍实测认证、课程列表与视频音轨均可访问，视频域名解析到校园内网地址；换到不通校园内网的网络时，需要先恢复对学校视频服务器的正常访问。

## 每门课程的独立设置

资料库中的 PDF 标题可以直接点击，使用本机 Google Chrome 打开原文件查看；Office 等文件已有转换后 PDF 时，标题打开该 PDF。原件和 AI 优化后 PDF 的下载按钮继续保留。此入口只接受资料库中已登记的文件编号，不接受浏览器传入的任意路径。

工作台左侧的“PDF 资料库”（`/course-files`，旧 `/notes` 自动跳转）支持按课程拖入或多选课件、讲义、作业等文件，按内容去重，保留原件并按需生成 PDF。提供 Mac 文件剪贴板复制、下载、闪念贝壳笔记匹配与附件上传预览。共享课程目录模式直接使用 `<资料库根目录>/<课程>/` 中的文件；旧布局仍使用课程下的“课程资料”目录。生成的课堂 PDF 保留在课次内部的导出目录，单节课关联的已存 PDF 保留在该课次的 `.note-pdfs/`，在课堂笔记中下载；旧资料列表中的单课笔记会保留全部版本并迁回对应课次。没有单课关联的外部复习 PDF 仍由原资料工具管理。详细设计、格式支持与试用步骤见 [课程资料库设计与使用](docs/课程资料库设计与使用.md)。

左侧选择课程分类后，可直接点击“全部设置”，按资料库与设备、AI 模型与接口、课程提示词与识别、实时录音、本机保存和 IdeaShell 同步分区配置。课程配置可分别保存：

- AI 修正系统提示词；
- 发给 Qwen3-ASR 的课程背景、教师姓名和专业词汇提示词；
- 每行一个的课程术语库；同一份词库会以受控预算提供给 ASR hotwords/提示词及后续 转写校对、整理和总结；
- 当前 MLX Qwen3-ASR 实现支持的生成参数：`max_tokens`、`batch_size`、`temperature`、`top_p`、`top_k`、`min_p`、`min_tokens_to_keep`、`repetition_penalty`、`repetition_context_size`、`prefill_step_size`、`chunk_duration`、`min_chunk_duration`、`hotwords`、`verbose`。

点击“保存此课程设置”后，配置同时写入应用设置和课程文件夹中的 `.qwenasr-course.json`。以后选择这个分类会自动载入。词库最多保存 500 条；ASR 最多取前 100 条且约占 1,200 tokens，后续 AI 按当前原文优先选词并最多占 4,096 tokens 或上下文的 5%，以较小者为准。`language` 在主界面选择，`system_prompt` 使用课程提示词；底层 `stream` 由网页的实时/批量流程接管，不作为自由参数开放。批量转写中的 `max_tokens` 是安全上限，程序还会按片段长度设置更小的实际值，以避免静音或噪声引发长时间重复生成。

默认滚动预览间隔约 6 秒，达到课程分段停顿时定稿。模型采用按需加载：点击转写时加载完整 BF16 权重，网页连接关闭、暂停或结束且最后一段处理完成约 5 秒后，自动卸载模型并清理 MLX Metal 缓存。Python 服务保留为低占用空壳，方便下次直接打开页面；下次转写会自动重新加载模型。

实时分段默认采用更适合课堂的设置：连续停顿 1.5 秒后定稿，单段最长 45 秒，滚动预览每 6 秒更新，并忽略有效语音不足约 0.55 秒的噪声小段。这三个主要时间参数可以在高级设置中调整并随课程保存；录音过程中修改会从下一段生效。

## Apple Neural Engine / NPU

当前 MLX 推理后端只提供 CPU 与 GPU 设备，不能把这个 Qwen3-ASR 模型直接切换到 Apple Neural Engine。要使用 Neural Engine，需要把完整的语音编码器、语言模型和生成流程转换并适配为 Core ML，且算子、动态长度和缓存都要验证；当前项目没有一个可保证精度和稳定性的现成转换。因此界面会明确显示 NPU 不可用，继续使用 Apple GPU + 按需加载/空闲卸载这一实际可用的节能方案。

## AI 修正与中英互译

ASR 不依赖任何 API Key。若要开启 AI 修正或翻译，可在网页的“AI 接口与高级设置”中填写：

- 接口地址：例如 `https://api.openai.com/v1`，也可以是兼容 Responses API 或 Chat Completions API 的本地服务地址。
- 模型：由对应服务提供的文本模型名称。
- 五分钟整理、长文本复核、转写校对和课后复习笔记各有独立的模型与提示词；只有对应功能启用或被点击时才会发送请求。
- Context Window：默认提升为 131,072 tokens；填写值仍应不高于所选模型和服务商实际支持的输入与输出总窗口。程序会预留输出空间、裁剪最旧上文并对长录音分块；预计超限的单次请求不会发送。
- 最大输出 tokens：每个 AI 功能单独配置；详细总结默认 16,384，其余默认 8,000，程序会同时受 32,768 和 Context Window 一半的安全上限约束，并据此决定全文生成或分块生成。
- 接口格式：支持自动识别、Responses API 和 Chat Completions API。`https://api.siliconflow.cn/v1` 会自动使用 `/chat/completions`。
- 每个功能页的“测试连接”都会真正发送一条短请求，显示实际回复、耗时或具体失败原因；未启用的功能不会因为缺少其 API 配置而阻塞录音。
- DNS、连接和读取超时会分类显示并做有限退避重试。`nodename nor servname provided` 表示请求在域名解析阶段就失败，模型尚未收到内容，不是上下文过长或推理太慢。
- API 配置与 Key：接口地址、模型、参数和提示词保存到 `~/.qwenasr/ai-settings.json`；密钥独立保存在 `~/.qwenasr/ai-provider-secrets.json`，按接口地址绑定。两个文件均使用仅当前用户可读写的 `0600` 权限。网页优先恢复本机文件，清空浏览器不会丢失配置；旧浏览器配置在本机尚无配置文件时迁移一次。点击“清除已保存配置”才删除工作台本机配置、密钥及浏览器缓存。不要在多人共用的系统账户中保存私人密钥。
- 系统提示词与上文：每次修正都会携带可编辑的系统提示词、当前原始转写，以及默认最近 2,000 个字符的录音上文；上文长度可设为 0–12,000。
- 口语清理：所有 AI 修正都会附加一条保护规则，删除无语义的“啊、哎、诶、嗯、呃、额、呢”等填充词，并合并停顿或自我修正造成的名词/短语重复；有语法含义的语气、引用和有意强调会保留。
- 自定义发送参数：填写请求 JSON。默认是 `reasoning.effort: none`、低 verbosity 和 `store: false`；Chat Completions 会自动映射为 `enable_thinking: false`。`model`、当前文本和系统指令由程序保留管理。

任务的提供商配置以服务端已保存设置为准。`.env` 中的旧 AI 模型或地址不能代替任务所需的持久配置；环境密钥只会在其接口身份与已保存地址一致时作为兼容来源。网页不会读取或显示这些服务端密钥。旧浏览器配置可经设置页的一次迁移写入本机设置，后续任务请求不能覆盖它。

## 说话人区分

Qwen3-ASR 本身负责语音识别，不包含说话人分离（diarization），因此当前版本不会自动标记“说话人 1 / 说话人 2”。这需要额外下载并常驻一个说话人分离模型，会增加内存、耗电和处理延迟，未默认开启。

./start_qwen_asr.command

默认地址是 <http://127.0.0.1:8765>。本机 `localhost` 可以直接使用麦克风；若要让局域网其他设备访问，浏览器通常要求 HTTPS。

录音 WebSocket 默认仅接受本机同源页面。通过局域网域名或 HTTPS 反向代理访问时，在 `.env` 的 `QWEN_ASR_ALLOWED_ORIGINS` 中填写实际网页来源（例如 `https://asr.example.com`，多个来源用逗号分隔，包含非默认端口），重启工作台后生效。

## MinerU 4 文件识别

本地 PDF 工具和课程资料库使用 MinerU 4.0.10，运行在独立环境 `~/.qwenasr/runtimes/mineru4/`。首次安装或换机器时运行 `scripts/install_mineru4.command`，它会下载并校验 Apple Silicon 所需的小模型与 llama.cpp 视觉模型。模型保存在 `~/.qwenasr/mineru4/models/`，不纳入 Git。

打开“全部设置 → MinerU 文件识别”，或访问 <http://127.0.0.1:8765/?settings=mineru>。质量档位包括极速 Flash、基础 Basic、标准 Standard 和高级 Advanced；标准适合日常识别，高级使用更多推理计算，适合难识别的公式与排版。可调整自动／强制 OCR／原生文字层、图像分析、小模型后端、视觉引擎、模型下载来源、处理窗口页数、视觉并发和推理内存预算。内存预算影响小模型批量大小，不是进程内存硬限制；视觉并发也受本地引擎实际容量约束。Mac 推荐 Torch/MPS 自动后端和 llama.cpp。ONNX 需要对应模型；vLLM、LMDeploy 需要各自支持的操作系统、硬件与依赖。

点击“保存 MinerU 设置”后写入 `~/.qwenasr/mineru-settings.json`（0600）。新任务保存参数快照，运行中的任务保持原参数；继续或重试未完成文件时使用最新配置。既有结果不会因设置变化自动重做；课程资料库会显示“按新参数重新识别”。本地 PDF 工具保留同名结果保护，比较不同参数前需先重命名或移走原件旁已有的 `(AI).pdf`。文档识别位置由持久化的 `inference-providers.json` 决定：本地模式在 Mac 处理，远程模式会把源文件发送到配置的推理节点。本地与远程 MinerU 使用各自的运行环境。

任务中心与课程资料库显示 MinerU 的“整体预估”进度、已用时间和预计剩余时间。估算按准备与加载、首个页段、后续页段、保存结果、传回结果、PDF 打包和最终保存分别计时；后续页段还会根据当前文档的实际速度修正。排队时间不计入处理耗时，完成前最多显示 99%，阶段内的 100% 不会当作整个文档完成。超出估算时保留进度并明确提示仍在处理，不显示来回移动的等待动画或归零倒计时。

耗时样本保存在 `~/.qwenasr/mineru-timing.json`（使用隔离数据根时位于其 `private/` 下），按执行机器、引擎、档位、OCR 配置和实际窗口大小分组，使用最近 20 次完整成功任务的单位耗时平均值。失败、取消、恢复旧远端任务和中途接入的观察不会加入平均值。初次使用没有匹配样本时会标注“初步估算”。历史仅包含耗时、页数、匿名操作标识与配置分组，不保存文档正文或访问凭据。

维护时可用 `scripts/observe_mineru_progress.py --output /安全目录/observations.jsonl` 只读观察已有队列；它不会提交任何识别。观察结束后，用 `scripts/calibrate_mineru_timing.py /安全目录/observations.jsonl --summary /安全目录/summary.json` 导入完整任务的耗时。采样是进度回调／轮询之间的间隔，不是每个底层模型函数的精确执行时间。旧服务尚未加载新后台时，页面暂按已完成页段显示稳定进度，并注明整体耗时预估尚未就绪。

AI 任务的服务商、模型、接口格式、提示词和密钥以 `~/.qwenasr/ai-settings.json` 与 `~/.qwenasr/ai-provider-secrets.json` 为唯一来源。任务中心的继续、重试、实时精修、课程回放和总结接口不会读取网页 `localStorage` 中的旧配置，也不会在请求失败时回退到 OpenAI 默认值；AI 操作缺少所需提供商时会提示先保存设置；基本录音和本地 ASR 在首次安装、清空 AI 设置或关闭 AI 功能时仍可使用。损坏的 AI 配置会关闭本次实时 AI 并提示原因，结束保存不依赖它。网页缓存只用于填写界面，不能决定实际请求。

课程资料库会把没有 `mineru-4-v1` 引擎标记的已存在 AI PDF（包括旧版索引和外部同步结果）显示为“旧版识别结果，可升级为 MinerU 4”。文件卡片可以单独升级，课程文件列表顶部的“升级旧版识别”会把当前课程中的旧结果按当前设置依次加入队列。原件不会改动；识别失败时原结果仍保留。成功替换结果后不再额外保存旧 PDF 的历史副本。

识别一次同时导出 Markdown、逐页内容列表和结构化结果，再把逐页正文、表格与 LaTeX 写入保留原页的 AI 友好 PDF。4.0 使用官方 Content List V1 渲染器适配打包器，避免沿用 3.x 的旧 JSON 结构；旧版 MinerU 3 的 MLX 解码补丁源码已移除，4.0 不再使用它；若旧环境留有 `~/.qwenasr/compat-backups/`，其中的恢复副本仍保留。官方档位和升级说明：[Tiers and Runtimes](https://opendatalab.github.io/MinerU/usage/tiers/)、[Migration to 4.0](https://opendatalab.github.io/MinerU/reference/migration_4/)。


## 日常备份与临时文件

在“设置 → 资料库与配置”点击“导出日常备份 ZIP”，可以打包当前课程资料、日常录音、转写、AI 笔记和已保存的配置。ZIP 包含 API 密钥及账号凭证，应妥善保管；模型、运行环境、旧任务和历史备份不纳入日常备份。打包会显示容量与文件进度，拒绝同时启动任务或修改配置；源文件在打包期间变化时会报错，不提供不完整的 ZIP。下载结束后，服务器删除临时 ZIP；需要再次下载时重新导出。

完成的课堂记录只长期保留日常 AAC。转写工作文件在归档后清理，不再保留 `.course-source.flac`；补课时从已保存的 AAC 重建前一课次的音频。闪念贝壳附件每次临时切分，优先直接复制 AAC 音频包，读取附件后删除分片。回听按请求临时封装为可定位的 M4A，响应结束后删除。远程识别保存最终 PDF 或转写结果后清理源文件副本和下载包；未完成任务仍保留恢复所需的数据。

`scripts/cleanup_daily_data.py` 默认只统计旧任务文件。加 `--apply` 后要求本机服务已停止，将旧文件移到本次专用的废纸篓目录，记录清单并核对保留文件内容；不会清空废纸篓。清理只移除任务相关数据，保留日常录音、转写、笔记、当前配置、模型和运行环境。

Markdown 预览会把公式里的 `[原文 S30](#source-30)` 等引用渲染为公式旁的链接，并兼容数组列间距写法。公式在闭合分隔符处结束，后面的引用和正文分别渲染；这些处理不改写保存的 Markdown。

## 模型准备与配置恢复

启动器与应用都使用 `qwen_asr_app.model_setup.model_path()`：优先读取 `QWEN_ASR_MODEL_PATH`，相对路径按项目目录解析，默认路径为 `models/Qwen3-ASR-1.7B-MLX-bf16`。ASR 模式读取 `~/.qwenasr/inference-providers.json`；设置 `QWEN_ASR_DATA_DIR` 后改用该目录下的 `private/inference-providers.json`。

本地或允许本地回退的安装，在确实需要 Mac ASR 时执行：

```bash
.venv/bin/python -m qwen_asr_app.model_setup check
.venv/bin/python -m qwen_asr_app.model_setup prepare
```

`prepare` 才会下载缺失的默认仓库权重到实际模型路径；已有单文件或分片索引模型不会重复下载。仅远程模式即使执行 `prepare` 也不下载本地模型。下载失败不影响之后启动网页或使用仅远程模式。切换回本地模式后需准备 MLX 依赖和对应模型；运行启动器会检查所需依赖。本轮测试只模拟下载和依赖安装，没有安装或替换正式环境。

资料库配置只有首次不存在、且不存在备份时才初始化默认值。JSON 损坏、路径／结构无效、读取失败或已有备份但主文件丢失，都会停止加载并保留原文件，避免把资料库切到默认目录。保存使用原子替换，`.last-good` 保留最后一次可用配置；新文件添加 `schema_version: 1`，旧版无版本配置仍兼容读取。

服务停止后可执行以下任一恢复命令。恢复保留原文件的 `.recovery-<编号>` 快照，不移动录音或资料，也不要求手工编辑 JSON：

```bash
.venv/bin/python -m qwen_asr_app.settings_recovery --restore-backup
.venv/bin/python -m qwen_asr_app.settings_recovery --root "/已有资料库的绝对路径"
```

读取权限或磁盘暂时不可用时，先修复该原因再重试。上述命令遵循 `QWEN_ASR_DATA_DIR` 和 `QWEN_ASR_SETTINGS_PATH`，可以先在临时目录演练。恢复不会绕过无法读取原文件的错误。

## 列表查询

`/api/library?category=课程名&limit=20&offset=0` 返回标题、课程、时间、时长、短摘要、任务状态和 `has_note`／`has_ai_summary`，不包含笔记正文、完整逐字稿或大型过程日志。`total`、`note_count`、`course_counts`、`calendar` 覆盖筛选后的整批资料，翻页不会使课程统计变成当前页数量。`date=YYYY-MM-DD` 按北京时间筛选，`next_offset` 指向下一页；每页最多 100 条。`ids` 可按编号读取任务关联的小列表。旧调用不带分页参数时仍返回全部摘要条目；录音详情与全文搜索接口保留原路径。

前端使用 20 条分页，并在打开记录后加载正文。课程首页、继续处理卡片和任务列表使用 ETag；无变化时返回无响应体的 304。资料库事件触发刷新，首页空闲时每 60 秒兜底校验、有活动任务时每 15 秒校验，切回页面会立即校验。服务器沿用录音文件缓存，尚未引入数据库全文索引。可用 `.venv/bin/python scripts/benchmark_library.py` 重现 100 条合成笔记的响应大小对比；不会读取真实课堂正文。

## 回归验证

AGY 接入的恢复规则：保留真实错误类型，退出码为 0 和普通启动诊断不构成“异常退出”。输出超限后，只在同一请求、完整资料读取、文件哈希与会话结束记录均通过校验时，接回完整 JSON 或逐字拼接连续的 JSON 续写；禁止猜测补齐、丢弃前文或把思考当作正文。无法确认完整性时，知识清单和笔记正文按完整来源拆批，已完成检查点继续复用。恢复结果仍须通过知识覆盖和来源校验。

新建的 AGY/Gemini 知识清单优先整节一次处理，按保存的上下文窗口同时预留预计回答和修复提案空间，不再由固定的输出目标提前切成四批；实际输出超限时，才把未完成部分按完整来源拆分。已有批次计划与成功结果保留原边界。任务保存独立的恢复位置，重启后即使界面草稿缺失，也能从当前任务的落盘结果恢复进度；尚未完成的模型回答可能需要重做，已验证批次、看图回执、正文和排版片段继续复用。已保存的知识清单响应另外校验请求、正文哈希与会话编号，避免退出后重复消耗同一请求。新版 AGY 1.4.3 的 `read_file(Path)` 与旧版 `view_file(AbsolutePath)` 均需读取清单内文件，前者的文字回执还会逐行对照原件；不会因为工具名变化而放开任意文件访问。

启动时暂时无法识别所选模型，最多间隔 2 秒、5 秒重试两次，始终使用保存的模型。配图阶段的网络、上游暂时不可用和读取路径失败也最多重试两次；登录拒绝、越界工具与取消不进入该重试。诊断只保存请求摘要、会话编号、退出码和错误分类，不另存原始 stderr 或账号信息。课后笔记的输出设置用于新批次的规划目标，AGY 不提供对应的硬输出上限参数；旧批次边界不因升级而改变。

回归覆盖正常退出伴随诊断、完整替换答案、多段 JSON 续写、残缺续写、来源变化、未授权读取、模型初始化恢复及重试耗尽、等待期间取消，以及拆批后的断点复用。排查手动与程序调用的差异时，以对应请求当时的模型和参数为准，不能用当前默认模型推断历史设置。合成回归之外，真实故障会话应在临时目录中重放，避免改写正式课程记录。

核心回归不需要模型、GPU、学校账号或真实外部服务，也不需要读取用户凭证：

```bash
.venv/bin/python -m unittest discover -s tests -q
node --test tests/*.cjs
.venv/bin/python -m unittest discover -s ai-infer-node/tests -v
PLAYWRIGHT_MODULE=/独立测试工具目录/node_modules/playwright node tests/browser/workspace-smoke.cjs
```

主应用测试由 `tests/isolation.py` 在导入应用前创建临时 `QWEN_ASR_DATA_DIR` 并禁止真实网络连接。`tests/test_review_capture.py` 的生产路径测试明确设置 `QWEN_ASR_TESTING=0`，使用真实 FastAPI／WebSocket 路由，模拟 ASR 和 AI 边界，使用合成音频验证真实 AAC 编码与落盘。损坏配置、恢复、响应丢失、并发限额与列表规模测试都使用合成数据。测试入口统一为上述隔离命令；已移除会扫描真实资料做指纹比较的旧包装脚本。

GitHub Actions 配置在 `.github/workflows/tests.yml`，包括 Linux／macOS 核心 Python、Node、合成浏览器以及 Linux 节点任务。`requirements-core.lock` 与完整运行时共用版本，去掉 MLX 依赖闭包；`scripts/lock_dependencies.py` 同时生成两份锁文件。浏览器依赖单独锁在 `tests/browser/package-lock.json`，CI 使用 Chromium，本机默认使用 Chrome；详见 [浏览器验收](tests/browser/README.md)。Linux 节点测试在 Linux 执行文件缓存回收场景，本机 macOS 会跳过该场景。

工作流需在提交并推送后才能由 GitHub 实际执行。建议在远端规则中要求这五个检查（Python 两个平台各一个、Node、浏览器、Linux 节点）通过后合并；本轮没有修改分支保护或其他远端设置。

调度器的优先级、公平性和取消行为由 `tests/test_phase1.py` 覆盖；实际课堂的下载、模型加载、排队、推理、精修和归档耗时从真实任务统计中评估，不再保留旧的睡眠模拟计时脚本。

图文笔记的资料包、独立逐页审查、PDF 下载、Windows 课堂省电模式及部署回滚说明，见 [操作与部署指南](docs/ILLUSTRATED_NOTES_AND_WINDOWS.md)。

任务中心按课堂集中显示当前步骤、错误与待核对内容，已完成和已恢复记录默认折叠；操作范围和恢复规则见 [任务中心说明](docs/TASK_CENTER.md)。

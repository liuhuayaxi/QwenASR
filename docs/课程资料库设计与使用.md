# 课程资料库

本次实现把三个需求串成一个流程：选择课程 → 添加文件 → 按需生成 PDF → 复制文件，或选定闪念贝壳笔记后上传附件。入口是工作台左侧“课程资料库”，也可打开 `http://127.0.0.1:8765/course-files`。

## 文件归属

沿用现有课程分类，支持新建课程。每门课可添加课件、讲义、作业、参考资料和其他文件，支持多选、拖入、按文件名搜索及按类型筛选。页面直接使用桌面课程文件夹中的文件；在页面添加文件会写入当前课程目录。页面上传每个文件最多 200 MB；从文件夹直接加入的已有大文件也会显示。同一课程内上传按 SHA-256 去重，同名而内容不同的文件分别保存。

选中左侧分类后，页面顶部提供“重命名分类”和“删除分类”。重命名会同步更新本地课程资料、录音分类和课程配置；删除只移除分类，资料和录音归入“未分类”，已有笔记内容保留。“未分类”作为默认分类不能删除或重命名。操作遇到同名目录或相关任务仍在处理时会提示原因；不会覆盖目标分类的同名文件，也不会改动闪念贝壳中的笔记。

```text
/Users/liuhuayaxi/Desktop/资料/
  <课程名>/
    <原版课件、讲义、作业等文件>
    <原有子文件夹>/                 保留原件原来的层级
    AI友好型/
      <原文件名>(AI).pdf
    上课录音/
      2026-09-11 15-35-00/
        recording.aac
        session.json
        transcript.json
        AI总结.md
        ...
    .qwenasr-files/index.json        隐藏的文件索引与附件关联记录
    .qwenasr-course.json             本地课程配置
```

页面和 Finder 使用同一份文件，不维护第二套副本。文件夹监听通过服务器事件通知页面刷新，通常在文件变动后的约一秒内显示；服务运行且页面连通时生效。关闭工作台服务后仍可在 Finder 整理文件，重新启动会重新发现文件；连接中断时页面自动重连并补充刷新。文件新增、内容替换、改名和删除都会反映到页面，隐藏索引按文件路径和文件身份保留关联记录。

页面提供文件重命名、替换原件和移到废纸篓。替换前把旧原件保留在本机废纸篓；移除文件时把原件及关联的 AI 文件一起移入废纸篓。Finder 中直接删除的文件不会被后台自动复制回来。原件更新后，旧 AI 文件保留并标记需要重新生成。

新录音自动保存在“上课录音/具体时间”中；有课程回放原始开课时间时优先用开课时间，其他录音使用记录中的开始时间。同一秒的录音会加短编号以避免重名。笔记标题可另行编辑，不改变时间目录。

本次整理的原资料库备份和移动清单保存在 `<项目>/local-data/library-migrations/20260912-214916`。桌面原有的 Syncthing 隐藏文件保持原样。

## PDF 转换

- PDF：使用与工作台“生成 AI 友好 PDF”相同的 MinerU 识别和打包函数，识别正文、表格与 LaTeX 公式，保留原页，添加可提取文字层，并嵌入逐页转写、Markdown 和内容映射。
- 图片：支持 PNG、JPEG、WebP、TIFF、BMP；先组成 PDF 页面，再交给同一套 MinerU 流程。
- Word、PPT、Excel、OpenDocument、RTF：通过 LibreOffice 转成 PDF，再使用 MinerU 识别。优先使用系统安装，也可使用本机已有的 Codex LibreOffice 运行时。可以设置 `QWEN_ASR_SOFFICE` 指向可执行文件。
- TXT、Markdown、CSV、TSV：先作为可阅读文本排版为 PDF，再交给 MinerU。准备阶段保留 Markdown 和 LaTeX 源码文字，不承诺渲染其全部语法。
- 其他格式仍可归档、下载、复制；转换按钮会给出格式不支持的提示。

转换和现有 PDF 工具共用单个转换锁，排队串行处理。页面显示 MinerU 阶段与百分比。关闭网页不会取消服务器中的任务；服务意外停止后会显示可重新转换。成功的 MinerU PDF 经过校验值检查后直接复用。之前使用旧版文字层生成的文件会显示“使用 MinerU 重新生成”。有歧义的公式、图示和复杂表格仍需对照原页核对。

## 复制与闪念贝壳

“复制原件 / 复制 PDF”写入 Mac 系统文件剪贴板，可在支持接收文件的应用中粘贴。接收应用是否支持粘贴附件由该应用决定，也提供下载入口。

闪念贝壳通过现有 OAuth 接入，账号区域沿用工作台设置，可在上传弹窗调整。访问令牌、刷新令牌、客户端注册、实际刷新端点和回调地址持久化在 `<项目>/local-data/<区域 API 域名>-oauth.json`，使用 0600 权限并原子写入。有效期遵循服务返回值，不人为缩短为单次会话。重启后自动恢复；访问令牌过期时优先静默刷新，只有刷新令牌也失效、授权被撤销或首次连接时才提供授权入口。临时网络错误、限流及服务故障保留本机凭证。主工作台不再为每次同步预先弹出授权窗口。

工具列表分页使用当前 MCP 2 接口 `list_tools(params=PaginatedRequestParams(...))`，读取 `input_schema` 和 `next_cursor`，避免旧参数导致搜索失败。

匹配顺序：

1. 这个文件以前上传过的笔记。
2. 当前课程已经同步到闪念贝壳的录音笔记。
3. 用户输入关键词后，从闪念贝壳搜索的最多三条结果。
4. 用户手工填写目标笔记编号。

候选结果不代表自动确认，最终由用户选择。在“预览上传目标”时读取目标笔记，并检查远端当前 `note_update` 的附件参数。显示实际文件名、版本、大小、课程、笔记标题与完整编号；点击“确认上传附件”才发送文件。此流程只追加附件，不创建测试笔记、不移动笔记，也不替换笔记正文。

附件编码按远端实时工具 schema 构建。如果没有可识别的文档参数，或接口要求同时替换正文，会明确提示改用复制文件。2026-10-07 已用现有授权验证新国内端点的 `documents: [{name, data}]` 参数，`data` 为 Base64，追加时无需传入笔记正文。自动上传本地上限仍为 20 MB；服务端对 PDF/Office 单文件上限为 50 MB、文本格式为 5 MB，实际仍须满足远端限制。格式、自动提取正文范围和授权兼容说明见 [IdeaShell MCP 迁移与附件能力](IdeaShell-MCP迁移与附件能力.md)。

成功记录以服务器、笔记编号和文件校验值去重。同一个文件可以上传到多份笔记；文件版本改变时可以另行上传。请求前记录发送中状态，成功后记录已同步，网络异常则保留“结果待核对”，不自动重新发送；先在闪念贝壳核对附件，再手动重新预览。

## 由用户试用

按本次要求，没有运行测试，也没有上传真实测试附件。若后台已在运行，需要先安全停止，再双击 `start_qwen_asr.command` 载入新代码。存在正在进行的录音或任务时，停止脚本会提示先完成或暂停。

建议先在一门课程中选择一份真实课件：添加文件 → 生成 PDF → 复制 PDF 并粘贴 → 连接闪念贝壳 → 搜索并选择笔记 → 预览 → 确认上传。观察 PDF 显示与可复制文字，以及附件是否出现在所选笔记中。

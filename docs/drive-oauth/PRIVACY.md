# 隐私说明

更新日期：2026-10-18

本说明适用于 QwenASR 的 Google Drive 个人备份模块。

## 访问和用途

备份模块经使用者授权，使用 `drive.file` 权限创建和管理通过本应用使用的特定 Google Drive 文件。上传内容为使用者选择的本地 PDF、转写 TXT/JSON，以及可选的笔记 Markdown。备份范围不包含应用配置、账号凭证、录音音频和模型。

模块读取 Google 返回的账号显示名称、邮箱和账号标识，用于显示已连接账号并区分不同账号的备份记录。模块读取其备份文件的元数据和校验值，用于增量上传和确认文件完整性。

## 存储和传输

OAuth 客户端配置、访问令牌、刷新令牌和上传进度保存于使用者电脑的应用私有目录。上传文件保存于使用者自己的 Google Drive。模块通过 HTTPS 与 Google 授权及 Drive API 通信，并沿用使用者自行配置的系统代理。

维护者不运营用于接收备份内容的独立服务器。该备份模块不出售 Google 用户数据，不将 Google 用户数据用于广告或训练通用 AI 模型。

本模块对从 Google API 接收的信息的使用遵守 Google API 服务用户数据政策，包括适用的 Limited Use 要求：
https://developers.google.com/terms/api-services-user-data-policy

## 停止和删除

使用者可暂停备份或关闭自动备份。选择“断开本机连接”会删除本机保存的访问令牌和刷新令牌，并关闭自动备份。使用者也可在 Google 账号的第三方访问设置中撤销授权。

云端副本由使用者通过 Google Drive 管理和删除；本地删除文件不会自动删除云端副本。本机 OAuth 客户端配置和备份记录可由使用者从应用私有目录中删除。

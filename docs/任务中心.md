# 任务中心

顶部主导航的“任务中心”位于“课程资料库”右侧，录音工作台、课程回放和课程资料库都使用同一入口。原录音面板中的 AI 任务视图已迁入该页面。

## 任务范围

- 录音 AI：课后 AI 总结、未精修内容、实时累计总结，沿用原任务及其已保存进度、模型、提示词与课程术语。
- 课程资料识别：所有课程中通过 MinerU 生成 AI 友好文件的任务，包括 Office、图片和文本转 PDF 后的识别。
- 本地 PDF 识别：原独立 PDF 工具的批量任务，可在任务中心新建，展开每个文件的进度、失败原因和结果路径，并下载生成的 PDF。

页面每 3 秒自动更新，可搜索任务、按状态、类型或课程筛选；勾选当前列表后，可批量继续、暂停、重试或取消。批量操作只作用于所选任务中当前支持该操作的项目，并逐项报告失败原因。录音任务可直接打开对应笔记，课程任务可跳回对应文件。

课程目录中的 PDF 从任务中心提交时，会自动关联课程资料索引，结果保存到“AI友好型”。其他本地 PDF 沿用原工具规则，在原文件旁创建“(AI).pdf”，不会覆盖已有同名文件。

## 进度与恢复

所有 MinerU 入口共享同一串行队列，不会同时启动多个识别进程。暂停或取消时先停止子进程，等待文件写入结束，再释放队列位置。Office 预转换也支持停止。

MinerU 暂停保留已完成文件；继续或重试会重新识别未完成的文件，不支持从未完成 PDF 的某一页恢复。关闭网页不会中断后台任务。服务重启后，未完成任务显示为已中断，需手动继续。

录音 AI 状态保存在录音元数据内，课程文件识别状态保存在课程资料索引内；本地 PDF 批次保存在 `~/.qwenasr/tasks/pdf-jobs.json`。任务中心展示这些记录中的当前结果与完成状态，不重复创建识别任务。

开发按用户要求未运行测试、浏览器检查或转换任务。

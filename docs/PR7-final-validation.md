## 关键发现与修复

| 范围 | 原问题 | 最终处理 |
| --- | --- | --- |
| 必含题 | 缩短后的模型条目只要出现题号，就可能被误当作完整题目 | 最终稿恢复完整题干、所有选项、题库已知答案；保留模型解析，漏题本地补齐 |
| 可选题 | 同日其他课次题目混入；必含题超过 14 后可选题没有独立额度 | 同班级、限定来源与时间、文字相关性过滤；独立最多 8 题；无课堂匹配不跨课补题 |
| 提示词 | 忽略 JSON 列表分隔符、标签等开销；极端输入超预算；压缩后必含标记丢失 | 按真实序列化长度计量；标签计入预算；保留必含标记，完整记录与模型摘要分开 |
| 多条笔记路径 | AGY 快速路径绕过预算；分块重复携带题库；规划与实际单次请求输入不同 | 文本、快速 AGY、完整 AGY 均使用有界题目输入；分块不重复发送整库；规划使用真实请求选项 |
| 图片笔记 | 文本路径没有把题目原图写进笔记资源包 | 文本及 AGY 路径共用图片附加、标记解析和资源登记 |
| 输出截断 | 快速笔记向分批函数传入缺少 coverage 的 payload，无法可靠续写 | 从已有来源建立批次所有权清单；恢复已完成批次，不再重试已完成的全篇请求 |
| 图片缓存 | 哈希信任旧元数据；模型变化、文件变化或并发同步时可复用过期转写 | 校验实际字节哈希、用途、模型和协议版本；拒绝空白/重复/遗漏回执；快照比较后写回 |
| 增量同步 | 缺失图片无恢复、教师修改长期不复核、每个活动扫描全题库 | 按活动读取缓存；缺图重试；完成活动低频复核；同 URL 图片在复核时重新校验；不误把部分失败记为成功 |
| 损坏缓存 | 读取损坏 JSON 可能视为空题库，或导致重新导入仍失败 | 读时明确报错；成功重新导入保留 `.corrupt-*` 原始副本后修复 |
| 隐私与 HTTP | 学生图片、签名 URL、私人作答进入不必要的模型/浏览器路径；响应未释放 | 模型排除作答/分数；不下载或转写学生答案图片；原始响应凭据净化；请求响应始终 dispose |
| 浏览器 | 受保护读接口需要同步调整前端；图片 Blob 未释放；旧请求覆盖新课程 | GET 和图片请求带守卫头；图片只读绑定课程的实际引用；最多 4 并发，切换时中止并释放资源 |
| 模型生命周期 | 子线程先清空 worker，事件循环稍后才置 idle，短暂出现无 worker 但 ready | 在公开 worker=None 前发布生命周期状态，并新增确定性回归 |
| 验收脚本 | 固定 25/40ms 等待导致真实 Response 消费竞态；仍检查已删除复习工具 | 等待响应体完成及明确 DOM 状态；保持原断言强度，校准已经移除的 UI，新增题库浏览器场景 |

题库字符预算不是整个请求的 token 预算。大量逐字稿、课件或人为开启的多阶段图文审查仍可能造成长耗时；本次未把这些耗时归因于题库，也未宣称解决所有 17 分钟级长任务。

请求守卫是单用户本机应用的浏览器同源保护，不是账户身份认证。此应用不能仅靠自定义请求头作为公网多用户服务。

# 独立审查修复候选（2026-10-09）

基线 `6e3dd2c`，候选分支 `codex/audit-isolated-fixes`。仅本工作树可写；原目录、用户资料、令牌、运行环境、生产进程与远端服务不部署、不重启、不改写。下载目录中的审查提示是参考材料，当前用户的隔离实施与 SSH 授权优先。

## 变更边界

1. `inference_providers.py`、新增 `remote_operations.py`：按任务冻结模式、参数、输入摘要和凭据引用；本地分支在远端校验前返回；只允许 ProvenNotAccepted 回退。
2. `ai-infer-node/client/remote.py`：先读收据再读源/凭据；先 fsync 再提交；对账、持久取消、持久结果与只下载恢复；不把 404 当成未接受。
3. `pdf_jobs.py`、`pdf_ai.py`、`course_file_conversion.py`、`course_file_routes.py`：私有输入/结果快照、generation 输出、远程等待不占本地锁；旧任务按 legacy-local 恢复；Office Flash 分流。
4. `model_runtime.py`、`live_session.py`、`upload_jobs.py`、`app.py`：本地 load 仍独立；final 段先存规范音频及参数；remote_only 不做本地 partial；恢复不改参数或 attempt。
5. `task_center.py` 与推理设置/任务页面：逐文件来源和恢复阶段；普通恢复、下载恢复、新识别/新本地任务是不同动作。
6. 节点 `server/{app,store,resources,config,cache}.py`、`workers/{asr_worker,text_merge,mineru_worker}.py`：幂等记录永久保留，结果 TTL 独立；未知资源不视为释放；有效结果可下载；固定执行契约；内容摘要；动态库回收关闭。
7. 新回归测试和 `audit-evidence/`：合成输入、模拟 HTTP、故障注入；记录本轮实际结果和未验证边界。

原有 `storage.py`、`shared_library.py`、`shared_files.py`、`service_control.py`、AI 总结/日期逻辑及应用生命周期不带入历史改造。

## 操作状态

`prepared → submitting → accepted → queued/loading/running/saving/unloading → completed → downloaded → built`

提交前失败可以 `proven_not_accepted → local_fallback`（仅 Preferred）。提交后任何未知、解析错误、凭据缺失、404、下载/构建错误均保留原 key，进入待恢复；不得转成本地计算。普通重试只恢复旧操作。新识别建立新 operation，保留旧操作。取消先写 intent，之后只对账/发取消，不提交新推理。completed 优先已有 bundle，否则只下载；构建失败保留 bundle。

## 验证与撤回

每批先运行本地回归和隔离远端测试；生产源文件清单及原变更保存在 `audit-evidence/original-*`。用户资料、模型和环境保留原处；不复制活动 SQLite、不删除 receipt。验收前不合并、不发布。撤回只停止使用候选目录，保留其任务状态供检查，不覆盖原程序或清理用户数据。

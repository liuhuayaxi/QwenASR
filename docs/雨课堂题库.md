# 雨课堂题库导入

QwenASR 可以只读导入学生本人在雨课堂（`changjiang.yuketang.cn`）的习题与答案，并在生成课程笔记时自动附上相关题目：

| 题库分类 | 雨课堂来源 | 内容 |
| --- | --- | --- |
| 课前/课后测试与考试 (`exam`) | 考试（活动类型 5）、试卷/测试（类型 4） | 题干、选项、正确答案、我的答案、得分 |
| 课上习题 (`lesson`) | 课堂（类型 14）中老师推送的题 | 课件页图片、题干、答案、解析图片、我的答案与批改状态 |
| 课件习题 (`courseware`) | 课件（类型 2）中嵌入的题 | 题干、选项、答案、我的作答 |

MOOC 视频（类型 15）等其他活动会被跳过。

## 首次使用

1. 安装 Playwright（使用本机 Chrome，无需下载浏览器；没有 Chrome 时再运行 `.venv/bin/python -m playwright install chromium`）：

   ```bash
   .venv/bin/pip install playwright
   ```

2. 登录：在课程资料页“雨课堂习题”（位于“课程知识检索”下方）点击 **登录雨课堂**，或运行

   ```bash
   .venv/bin/python -m qwen_asr_app.yuketang login
   ```

   会打开一个 Chrome 窗口，用微信扫码。登录状态保存在 `<项目>/local-data/yuketang/browser-profile`，之后同步在后台无窗口运行。登录过期时同步会停止并提示“需要重新登录”，不会自动尝试登录。登录成功后会顺带只读读取一次“我听的课”课程列表（`/v2/api/web/courses/list?identity=2`），缓存在 `courses.json` 中，每次同步时刷新。

3. 绑定课程：在“雨课堂习题”的下拉框里选择课程（显示为“课程名 · 班级 · 老师”，与当前课程名最接近的会被预选），点 **绑定**，班级编号和学校编号自动填好。绑定后只显示课程名与 **改绑** 按钮；改绑会替换原来的绑定。也可以用命令行：

   ```bash
   .venv/bin/python -m qwen_asr_app.yuketang courses [--refresh]          # 查看/刷新课程列表
   .venv/bin/python -m qwen_asr_app.yuketang bind --course "通信原理 C" --classroom 26260946 --university 3278 [--replace]
   ```

   课程改名时绑定自动跟随，删除课程时自动解除。

4. 同步：页面上点 **同步**（会读取新题目并自动转写图片题；“⋯”菜单里有“全部重新读取”“只转写图片题”“刷新课程列表”“解除绑定”），或运行

   ```bash
   .venv/bin/python -m qwen_asr_app.yuketang sync              # 所有已绑定班级
   .venv/bin/python -m qwen_asr_app.yuketang sync --course 光电子学
   .venv/bin/python -m qwen_asr_app.yuketang sync --classroom 26260946 --refresh
   ```

   同步只发送 GET 请求，每次请求间隔约 1 秒（`--delay` 可调大），不会提交答案或修改雨课堂上的任何内容。已完成的活动按指纹增量跳过；图片文件缺失会立即重试，已完成活动每周低频复核一次以发现题目修改；答案未公布、老师未开放试卷查看、主观题未批改或图片下载失败的活动会在之后的同步中重新核对。

5. 图片转写（可选）：只有图片的题目（课件页截图、解析图片、主观题）可用当前“笔记总结”的 AGY CLI 读图通道转写，结果按图片哈希缓存，可随时中断后继续：

   ```bash
   .venv/bin/python -m qwen_asr_app.yuketang transcribe --course 光电子学 [--limit 5]
   ```

   未配置 AGY 时会跳过并保留图片，题目仍会以“题干仅有课件图片，尚未转写”的形式参与笔记。

其他命令：`status [--course 名称]`、`list --course 名称 [--query 关键词] [--source exam|lesson|courseware]`、`unbind`。全局参数 `--store DIR`、`--profile DIR` 可指定题库目录或 Chrome 资料目录。

## 生成笔记时的使用方式

批量文本笔记 `batch_ai`、默认 AGY 快速笔记 `fast_note` 和完整图文笔记 `review_notes` 共用同一份本节题目清单。生成笔记只读取本地题库，不触发联网同步或图片模型调用。

### 必含题与可选题

本节课对应课堂的全部课上习题、以及归属于该课次的课前测题目，都是必含题。必含题在最终笔记中不受题数限制，不以相关度低为由删除。

课堂时间窗为 `[创建时间, max(创建+100 分钟, 最后推题+5 分钟)]`，与录音重叠的同日课堂一并匹配，以支持中途重开课堂。没有重叠时，只允许距课堂时间窗不超过 30 分钟的近邻回退；相隔数小时的同日录音不会直接匹配。没有匹配到课堂时不注入其他课次题目。

课前测以 `(上一节结束, 本节结束]` 为发布时间范围；没有上一节时回看 7 天。上一节课后 3 小时内发布的测试，如果标题与上一节明显更相近，则不归本节。时间和标题匹配仍是启发式规则，不等同于教师显式指定的归属。

可选题独立最多 8 道，仅从同一匹配班级的测试、考试及课件题中选取，要求与逐字稿有文字相关性，且不使用本节结束后发布的题目。同日另一节课的课堂题不会作为可选题混入。旧 PR 概要中的“所有题最多 14 道”不是当前的必含题规则。

### 模型预算与完整性

完整题目在本地保留；模型侧使用独立副本。`fit()` 对 JSON 列表实际序列化长度施加默认 14,000 字符限制；`prompt_block()` 还将数据块标签计入同一预算。字符数不是 token 数，整条请求仍需由笔记流水线按模型上下文另行计量。

预算不足时优先保留必含题并缩短题干摘要、解析和图片转写。过长的选项或答案不截成貌似完整的内容，而是省略并标记“内容已压缩”。极端情况下连所有题号都放不下时，模型只收到有界子集，最终笔记仍由本地完整清单补齐。

生成后，程序先按独立条目的题号匹配，再使用完整 id 或题干辅助匹配；同一条目不能覆盖多个必含题。已生成的必含题也会恢复完整题干、选项及题库已知答案，同时保留模型解析。未公布的答案明确标为“待核对”，不冒充官方答案。图片题会把本地原图写入笔记资源目录，文本模型路径同样支持。

分块文本笔记和 AGY 输出截断后的分批写作不重复发送整份题库，最后统一补全，不为漏题另发模型请求。断点续写复用已完成批次；实现版本变化会使旧任务缓存失效。`upgrade_pdf` 只重新导出已有正文，不自动重写历史笔记。

AI 在正文用“📝 考点”关联习题，解释正确答案和错误选项。个人作答、对错、得分不进入笔记模型输入，也不进入确定性附录；这些信息仍可在本机题库浏览和检索中使用。

## 数据与隐私

- 题库位于 `<项目>/local-data/yuketang/`（设置了 `QWEN_ASR_DATA_DIR` 时为 `$QWEN_ASR_DATA_DIR/private/yuketang`，也可用 `QWEN_ASR_YUKETANG_DIR` 覆盖），目录权限 700，不在仓库、也不在可能被云同步的课程资料库中：
  - `bindings.json` 课程绑定；
  - `classrooms/<班级>/questions|activities|images|vision|raw/` 题目、活动状态、下载的图片、转写缓存和原始响应（原始响应仅供本机排查，写入前会去掉图片 URL 的查询签名）。
- 浏览器资料目录 `browser-profile/` 含登录 Cookie，请勿分享。
- 题目中保存的图片地址已去掉签名参数；页面通过 `/api/yuketang/image/...` 读取本机已下载的图片，不直接访问雨课堂。
- 所有题库读写接口均要求 `X-QwenASR-Client: course-files`，并复用课程资料页的同源校验。此请求头是浏览器请求守卫，不是用户身份认证；服务仍按单用户、本机工作台使用，不应直接暴露到公网。
- 图片接口只允许读取仍绑定到有效课程、且被题目引用的非学生作答图片；响应禁止缓存。前端最多并发加载 4 张图片，切换课程或筛选结果时取消旧请求并释放 Blob URL。
- 原始诊断响应在落盘前移除 URL 查询参数及常见凭据字段。读取损坏题库时会明确报错，不把损坏当作“没有题目”；成功重新导入时保留 `.corrupt-*` 原始副本后修复。
- 图片转写缓存按实际文件哈希、图片用途、模型与解析协议版本区分；空白、遗漏、重复 image_id 的回执不会标记成功。写回使用输入快照校验，避免覆盖同时更新的题目。

## 已验证与未验证的接口

已用真实账号只读验证：活动列表 `/v2/api/web/logs/learn/<班级>`、考试封面 `/v/exam/cover`、考试域名的 `show_paper`/`problem_results`/`cover`（需先经 `/v2/web/trans/<班级>/<考试>` 页面换取令牌，且同一时间只能打开一份试卷）、试卷 `quiz/personal_result` 与 `quiz/problem_shape`、课堂报告 `classroom-report/student/lesson-info|detail` 与 `problem/student-answer`、课件 `cards/detlist`。

尚未在真实数据上验证：课件中嵌入习题的解析（现有课件均无习题）、选择题型的 `quiz/problem_shape`（现有测试均为填空/判断）、登录过期时的确切响应（目前把 3xx 跳转、缺少 sessionid Cookie 以及 userinfo 返回 401/403 视为“需要重新登录”）。

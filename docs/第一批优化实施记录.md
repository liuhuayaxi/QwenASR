# 第一批优化实施记录

本次交付可直接用于“登录后勾选课程，合并音频并生成笔记”。保留原有资料格式、模型和 AI 提示词。

## 已实现

- **任务恢复**：持久化已选课次及提交时的设置；重启登录后接回已提交、未暂停的队列；主动暂停后保持暂停。网络错误保留进度，点击“继续已保存队列”重试。不会检查漏录或新增未选课次。
- **确认后不丢分段**：PCM 和独立分段提交文件先刷盘，再更新录音元数据。恢复检查 SHA-256、长度、连续序号；处理音频已保存但元数据尚未更新的中断点。主服务重启后仍可查询已有任务状态。
- **实时优先**：定稿、预览、后台按优先级排队；过时预览在模型加载前丢弃。最多连续插队 8 次或等待超过 30 秒后给最早任务机会。正在执行的 GPU 请求不抢占；出现实时工作时，后续后台请求缩短至最多 25 秒音频。
- **取消保护**：推理线程结束后才释放 GPU 执行锁，避免取消请求后两个任务同时读写模型队列。
- **精修缓冲**：512 个已保存文本段的有界缓冲，队列内不存 PCM。AI 慢时可继续下载和转写；超过上限才等待。完成的精修和原文都参与恢复。
- **按来源去重与补课**：使用视频 ID + 源分段 ID 匹配已有课堂；A → A+B 复用 A 的本地底稿，只获取 B；连续时间轴保持不变。已有人工文字及自定义标题保留，补齐前创建 `.versions/` 备份。不同顺序或涉及多份笔记的重叠拒绝自动合并，提示核对。
- **耗时记录**：ASR 排队、模型加载、推理分别统计；段落记录 AI 等待/处理耗时；课程状态提供首段文字、下载及归档耗时。健康接口提供最近 500 次请求的 p50/p95；尚无样本时为 `null`。
- **启动与退出**：两个启动脚本共用后台进程管理器。关闭终端不再结束服务；停止脚本先冻结新请求并检查录音、转写、课程及 AI 任务，验证进程身份后才停止。繁忙时保留服务运行。
- **测试隔离**：临时应用数据目录覆盖资料库、设置、密钥、OAuth 与学校状态；测试禁止真实 TCP 连接。增加真实资料文件校验脚本。本地 Git 保存修改前的代码基线，凭证、录音、模型及生成文件不进入版本管理。

## 验证

- 90 项 Python 测试通过；前端 5 个会话控制场景通过；课程页面脚本和启动脚本语法检查通过。
- 验证 10 次并发提交只创建一个任务；相同分段重放不重复写入；音频提交后元数据写入前中断可恢复；损坏音频在送入模型前被拦截。
- A 完成后重新加载任务、补入 B，模型只调用两次；仍是一份课堂记录。两段无损缓存逐样本一致，人工标题和文字保持不变，备份存在。
- 故意阻塞 AI 后，12 段 ASR 全部落盘；精修完成后中断、恢复不重复执行 ASR。
- 验证实时请求优先、公平调度、过时预览丢弃，以及推理取消后等待线程排空。
- 全套测试前后，93 个真实配置与资料文件哈希一致（含本轮新增的启动器状态文件）。未调用真实 AI、未生成额外课程笔记。
- 统一启动器现在只启动一个 uvicorn 服务，课程页面挂载在 `/course/`；课程页面自动登录成功并加载本学期 7 条课程，安全停止与重新启动通过。

模拟排队实验使用固定后台请求和实时请求，各采样 30 次。FIFO 的等待 p50/p95 为 107.93/111.71 ms，实时优先为 14.69/18.45 ms。**这只是调度验证，不能换算为真实 ASR 提速倍数。** 可用 `scripts/benchmark_scheduler.py` 复现，实际结果随系统调度略有变化。

## 仍需后续实施或验证

- 本轮沿用课程队列文件、录音元数据和段落文件，尚未迁移为主服务的统一 SQLite 台账。精修缓冲也仍属于当前录音任务；跨功能的独立持久化 AI 队列、连接池和全局并发控制留到下一批。
- 新归档保留压缩无损底稿，会增加磁盘占用；旧记录没有无损底稿时只能复用原 AAC，因此不声称旧 AAC 补齐是无损的。补齐备份保留旧音频和笔记。
- ZIP 已改为点击下载时在线程中临时生成，传输结束或中断后自动删除，不再在录音结束和 AI 内容更新时反复重建，也不留在录音文件夹。增量写入、通用版本冲突处理、检索和音频时间跳转尚未实施。
- 为避免未经确认地批量删除已有文件，旧版本已经生成的 `recording-and-transcript.zip` 暂不统一清理；下次下载对应录音时会删除该旧包，随后只使用自动清理的临时 ZIP。浏览器保存到“下载”目录的用户副本不受影响。
- 同一服务进程内的 AI 请求复用 HTTP keep-alive 连接，并在服务退出时统一关闭连接池，减少逐段精修时反复建立连接的开销；模型、接口格式和提示词不变。
- 页面位于后台时，课程状态轮询从 2 秒降为 15 秒，主工作台暂停普通 AI 状态轮询；回到页面后立即刷新，减少无效请求和文件扫描。
- 本轮没有重新跑完整两节课的真实 GPU/AI 压测，也没有完成中文、英文、中英混讲的整套人工质量评测。模型、默认采样参数与 AI 提示词未变；真实速度和长课堂内容完整性需要用实际任务指标继续评估。

## 使用与回退

继续使用 `start_qwen_asr.command` 或 `start_course_sync.command`。停止使用 `stop_qwen_asr.command`。用户主动暂停后，在课程页点击“继续已保存队列”。

代码基线可通过本地 Git 查看；本次修改保持为工作区差异，便于审阅。额外代码备份为 `output/backups/phase1-before-20260910-222829.tar.gz`。回退代码前先安全停止服务；不要恢复或覆盖真实凭证、资料库和用户配置。

## 已实现行为

1. 首页“继续处理”卡片列出最近课堂、原文可读状态、笔记状态、IdeaShell 关联状态，以及相关任务的阶段、失败信息和继续/重试入口。任务读取失败时保留上次内容并显示连接提示；首次读取失败不会把未知状态显示为零任务。
2. 浏览器记住最近课程与课堂 ID；已有活动会话优先于最近课程。空标题使用课程名与日期生成，录音开始前无需填写完整标题。
3. 识别来源按推理回执显示。配置 `remote_only` 只表示失败策略，不证明 Windows 已连接或真正执行过推理。没有回执时显示来源待确认；不会自动发起远程连接检查。
4. 麦克风或上传完成后，从当前页面直接打开课堂笔记。课程回放页面在最近入库记录中提供相同的课堂笔记链接；不会在多课次队列运行中强制跳走。
5. 原“录音库”显示为“课堂记录”，原“笔记管理”显示为“复习资料”，AI 总结显示为“课后复习笔记”。外部 PDF 的提示词和上传表单放在默认折叠的“导入外部复习资料”入口。存储键、API 字段、文件名和 IdeaShell 旧归档章节标记保留。
6. 任务中心默认列出待处理、运行中和暂停任务，同一录音按 ID 分组，其他任务按课程分组。完成任务仍可从历史筛选查看。批量继续/暂停/重试/取消在选择任务后显示；一键重试和历史清理放入高级历史操作。
7. `/workspace?category=课程名` 提供概览、课堂记录、课堂笔记、课程资料、问答与复习五个标签，以及课程任务抽屉。已有页面通过同源嵌入复用，旧 URL 均可独立打开。
8. 课堂笔记增加“课堂问答”快捷按钮，保存当前修改后打开该课堂的转写和问答。工作区“问答与复习”可以选择课堂提问，也可以打开外部 PDF 资料。
9. 首页状态模块拆到 `static/js/workbench/continuation.js`，共享任务分组与来源显示逻辑。README 更新为课程入口加六个兼容入口。

课程回放目前仍有一个跨课程队列。课程工作区与任务抽屉显示这个全局队列，具体课次在任务详情/回放页查看；没有伪造每门课程的独立队列。

## 本机预览

在此工作树运行：

```sh
/Users/liuhuayaxi/AIcreatedapplication/QwenASR/.venv/bin/python scripts/preview_workspace.py --port 8876
```

打开 `http://127.0.0.1:8876/workspace`。启动器将设置、录音、任务、凭证放在工作树的 `.workspace-preview/`，跳过正式 `.env`，清除 shell 中继承的 AI Key/Token 与正式资料库路径覆盖值。该目录默认为空，模型按原逻辑在实际识别时才加载。原应用端口不变。按 Ctrl+C 停止此预览进程；删除预览数据目录只影响预览资料。

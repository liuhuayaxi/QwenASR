# 任务中心

打开 `/tasks`，默认查看当前进展。同一堂课的转写、精修、课后笔记和课程回放进度集中在一张课堂卡片里；独立资料识别按资料显示。相同标题或同一门课程的不同课次不会合并。

- **进行中**：显示现在执行的步骤与实际活动。排队、等待重试和正在停止保留各自状态。
- **需要处理**：当前确实失败、中断或有未解决错误的步骤。一堂课可以同时有运行中的步骤和错误，两种计数均保留。
- **待核对**：转写已有结果，但数字、公式或专业内容的修改仍需核对。它不代表语音识别失败，也不等同于尚未处理。
- **尚未开始**：未执行且没有错误的步骤，可展开查看。
- **已完成与历史**：默认折叠。旧错误只有在同一来源的当前内容、版本和向量结果核实恢复后，才显示已恢复；原始失败记录仍保留。

课堂卡片保留原任务的操作。课程队列控制会影响队列中的全部课次，按钮会明确说明范围；一张卡片里的进度仅对应本堂课。批量操作按原任务编号去重，不会因为同一队列出现在两堂课下面而重复提交。

自动刷新保留已勾选步骤、展开详情和键盘焦点。执行操作后，旧读取结果不会覆盖新状态；短暂断线保留已显示的内容并提示重连。默认全选不会把人工核对项或全局队列控制混入计算任务。

继续失败的笔记会沿用已保存的接口、模型和任务检查点，不重新下载或重做已经完成的语音转写。AI 资料连接错误保留类型以支持有限自动重试；凭据被拒绝、额度或参数问题不会伪装成网络问题无限重试。完整图文笔记包含课件读取、写作、LaTeX 排版和独立逐页审查，使用独立的有限总时限；每次模型请求、编译和自动修订仍各有上限。

开发与维护：`/api/tasks` 保留原有 `tasks` 及原始任务状态和操作编号，新增 `groups`、`group_counts` 供课堂视图使用。显示分组、恢复说明和历史折叠均不修改任务所属模块的原始回执。按分类筛选后，列表和数量对应同一范围。

LaTeX 分批写作显示当前批次和已保存批数，依据与当前正文绑定的检查点更新，不拿之前的知识清单“6/6”冒充排版完成。恢复日志保留上一轮错误；本轮正常运行时清空当前错误，避免历史故障看起来仍在失败。

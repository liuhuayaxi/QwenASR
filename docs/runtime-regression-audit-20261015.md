## 已落实的修复

| 问题 | 原版可复现的行为 | 修复 |
| --- | --- | --- |
| 本地推理连续取消 | 第二次取消会取消等待中的包装任务；实际线程未结束，推理锁、调度槽和活动计数已经释放 | 新增 `await_owned_task`，每次等待都屏蔽外层取消，线程结束后再传播取消 |
| 远程转写连续取消 | 发出停止信号后，再次取消会让调用方先于远程操作线程退出 | 保留停止信号，同时等待操作线程结束；已写入的音频、请求快照和结果不会因提前清理而丢失 |
| 模型加载错误与取消竞争 | 已经取消的加载遇到随后发生的线程异常，可能走普通错误分支而不再向调用方报告取消 | 保留取消语义，并读取线程异常 |
| 模型子进程未退出 | `terminate()` 后进程仍存活，代码仍清空进程与队列引用，并将状态标为 idle | 增加 kill/join；仍无法退出时保留引用、阻止重新创建进程，并报告 error 状态 |
| ASR、实时分段与上下文参数 | 小数型整数参数被截断，部分布尔值被当作数字，无穷大或极大整数可能泄漏 `OverflowError` | 拒绝非法类型及非整数值，将转换失败统一为 `ValueError`；保留合法数字字符串、整数浮点值及既有上下文零值默认约定 |
| 损坏的远程收据 | JSON 虽能解析但结果是数组、null、字符串或无效 state，后续 `.get()` 等操作失败 | 统一标为 `receipt_corrupt` / `recovery_required`，阻止错误的本地重算与结果接收 |
| 课堂校对遗漏前导零小数 | `NA=.22` 被改为 `NA=.20`，原数值保护规则没有检测到变化 | 纳入 `.22`、`-.22`、带指数及单位的小数，保留原转录并将修改候选标为待核对 |

没有调整模型版本、模型精度、MinerU 档位、默认推理设备或课程提示词。PDF 转换及文件发布已有的取消保护保留原实现，只增加对照测试。

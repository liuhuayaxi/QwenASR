## 第一轮修复一并纳入

课程工作区刷新保留已加载的分页窗口，刷新和分页串行，切课中止旧请求并隔离 A→B→A 的旧响应。分页失败保留现有内容并提供重试，键盘加载后定位新增内容。同一 iframe 目标不重复重载，切课保留当前标签。分页样式单独放入 `static/workspace-pagination.css`，不改写整份工作区样式。

笔记自动保存将进行中的写入和结果未知状态计为未确认；把文字改回旧值不能提前显示“已保存”。保留版本冲突、草稿恢复和失败重试机制。

# 智能课堂新版：使用、配置与恢复

本次代码在独立分支 `codex/course-knowledge-classroom-20261014` 和受管理工作区中实施。原项目 `/Users/liuhuayaxi/AIcreatedapplication/QwenASR` 的代码没有被覆盖；没有推送 GitHub，也没有执行正式笔记批量同步。

## 启动方式

双击桌面的 `启动 QwenASR 智能课堂.command`，或工作区根目录的 `启动智能课堂新版.command`。它先检查原版是否正在录音或处理任务；有任务时保留原版并退出。空闲时安全停止原版服务，再从独立工作区启动新版，继续使用端口 `8765`。这个端口同时保持原有 OAuth 回调地址，避免丢失 IdeaShell 授权。

新版复用原来的资料库设置、课程目录、录音、已转换 PDF、ASR 模型和本机授权。新版的硬件路由单独保存在 `classroom-inference-providers.json`，初始使用 Mac 本机；继承原加速地址和令牌位置，用户可明确启用 Windows。原版的 `inference-providers.json` 不修改，旧任务继续按原回执和快照恢复。只新增派生知识索引、课程身份标记及按课次保存的速记文件。启动脚本不会切换原项目分支、修改原源码、移动原件或重新下载 ASR 模型。本次交付没有替用户执行这个正式切换入口。

开发验收页面是 `http://127.0.0.1:8898/`。它使用 `.workspace-preview` 下的课程副本，带“隔离测试页”提示，并拒绝外部笔记推送、拉取及核对写入。正式推送请使用正常授权的 `8765` 页面，不能把测试页当作正式版本。

## 第一次使用

1. 在“PDF 资料库”选择一门课程，打开“课程知识检索”。课程资料仅使用已完成的 MinerU 转换 PDF 建库；优先读取 PDF 中逐页标记的 MinerU 转写层，排除原页面的混乱文字和重复附件索引。旧版无逐页标记的文件复用 PDF 内嵌 MinerU 转写。点击“重建当前课程索引”完成第一次建库；原文件和转换结果仍在原目录，不会重新转换。
2. 未转换资料显示“等待 MinerU 转换”，暂不进入检索；转换完成或增加新内容后自动增量收录，未变化内容复用已有向量。原件已更新而转换结果未更新时，旧结果退出检索，等待重新转换。课堂定稿转录、速记和术语继续参与索引。旧原件与重复转写附件索引只失效，历史和原文件保留。任务中心显示“处理位置：Mac 本机”，排队任务可正常查看和取消。
3. 进入“录音工作台”。转写保持主区域，侧栏有“速记、相关资料、问答”。实时 ASR 使用 Mac，Windows 加速设置保留用于课后回放与资料转换。
4. 在速记里输入关键词或疑问。原始输入立即保存；“当前讲授、刚才讲授、指定时间”支持迟记和回指。模型结果单独存为建议，分出课堂依据、资料补充、AI 解读及待核对内容。
5. 人工改过的正文保留。晚到的建议不能直接覆盖；采用新建议时保留手记并合并补充。可以驳回、重新增强、锁定、查看来源和撤销。取消会停止自动重启；需要时明确重新生成。
6. 问答可以选择本节课、最近三分钟、本课程资料或本堂课全文。完整课堂模式保留全部定稿转录；题干、公式或指代不够明确时请求补充。
7. 保存录音后继续使用原有精修、课后笔记、导出及 IdeaShell 预览和同步流程。保存的手记与已接受增强内容可进入组合导出；未接受建议不会被自动当成正式同步正文。
8. 资料识别完成后，资料卡片隐藏“查看识别任务”，下载、复制及重新识别等操作保留。课程概览中的“最近课堂”直接全屏打开原笔记阅读器，关闭或按 Esc 后返回原课程、标签与滚动位置；关闭前沿用原来的编辑保存保护。

## 本机模型

实测环境：Apple M4、24 GiB 内存、Python 3.12。现有环境已具备所需依赖，本次未升级原环境中的软件包。新增依赖版本记录在 `requirements-knowledge.lock`；换机时优先复用现有环境，缺少依赖再安装该文件。

默认向量模型为官方未量化 `Qwen/Qwen3-Embedding-4B`，本机 PyTorch MPS，最后有效 token 池化，float32 L2 归一化，2560 维。模型、版本、维度、查询提示、文档提示、池化与归一化一起组成契约；查询不会临时换用另一模型的向量。

本机已经准备并校验了官方 4B、0.6B embedding 和 4B reranker 权重。它们保存在原项目的 `models/knowledge`，ASR 模型沿用原来的 `models/Qwen3-ASR-1.7B-MLX-bf16`。向量模型按需进入独立进程，默认空闲 30 秒退出；实时 ASR 和向量处理共用资源租约，批次之间让出计算资源。不会无条件常驻本地生成大模型。

换机后可使用设置页的“准备所选模型”，或：

```sh
./.venv/bin/python -m qwen_asr_app.knowledge.settings prepare --model Qwen/Qwen3-Embedding-4B --root /完整路径/models/knowledge
./.venv/bin/python -m qwen_asr_app.knowledge.reranking prepare
```

更换 embedding 模型后更新课程索引。旧模型向量不会参加新模型查询；中文词法索引仍可查询，界面会显示需要补建向量。重排默认关闭；它对少量候选单独运行，默认 45 秒预算。课堂或索引正在占用模型时继续使用排名融合，课后可明确执行“精排结果”。

速记增强默认使用已实测可用的 AGY `gemini-3.8-flash-high`、High 推理、1,048,576 输入窗口、4096 最大输出。速记、课堂问答及课后精修有各自服务端配置。新增速记 API 密钥保存在独立的受保护密钥文件，避免覆盖原问答设置。没有静默降级到小模型。

## 数据与恢复

| 数据 | 位置与用途 |
| --- | --- |
| 原件、录音、既有 PDF、笔记 | 原来的课程目录，继续作为权威源 |
| `.qwenasr-course-id.json` | 稳定课程身份，随课程文件夹保留 |
| `.knowledge.db` 及 WAL | SQLite 元数据、版本、FTS、向量及知识任务；可重建 |
| `classroom-notes.json` | 该次课堂的原始速记、编辑版本、建议、引用、任务和历史 |
| `intelligence-settings.json` | Mac 受保护配置目录中的速记模型设置 |
| `intelligence-secrets.json` | 独立且权限为 0600 的速记 API 密钥；不进入代码或日志 |

新增表不修改既有录音和资料格式。来源切换在 SQLite 事务内完成；删除先失效，恢复文件后重建；相同正文和模型契约复用向量。旧向量及时清理，历史正文和引用元数据保留，避免增量课堂积累多份相同大向量。正式 ASR 保存后再进持久化索引，滚动预览不作为定稿证据。

备份继续使用原有日常备份机制，包含原件、课程身份、速记正文与历史；正在增强或建库时会要求先完成或暂停。可重建的 `.knowledge.db`、WAL 和 SHM 不进入日常备份，避免复制出不一致的 SQLite 快照。恢复后重新建索引即可。独立备份知识索引时，应停止服务后同时保存数据库及 WAL，或使用 SQLite 的在线 backup API；不要在写入时只复制一个数据库文件。保留课程身份标记和每次课堂的 `classroom-notes.json`，它们承担来源和版本关系。

恢复旧程序：关闭新版服务，运行原项目的 `start_qwen_asr.command`。原源码未改变，无需回滚 Git。旧程序会保留新增文件，既有录音、转录和 AI 笔记继续可用。重建知识索引时，仅备份并移走派生数据库，保留原件、课程身份和速记文件，再更新索引。

## 本轮边界

Windows 的既有 ASR／MinerU 任务回执和恢复路径保留，新增知识库和课堂助手以 Mac 为主。本轮没有部署新的 Windows embedding／reranker worker，也没有强制关闭用户的 Windows 机器。Mac 路径验收采用本机处理，不依赖 Windows 接受任务。

扫描件和没有可靠文本的复杂资料会明确显示需核对解析；优先复用现有成功转换和附件，不自动启动新的 MinerU。图片中的公式仍需对照 PDF 原页。高风险纠错候选保留原文并在阅读器提示回听，本轮不提供批量自动接受数值修改。

本轮完成短程真实课堂回放及故障回归，没有建立人工逐字音频金标准，也未完成持续两小时真实麦克风课堂、真实断网再联网或新版正式 IdeaShell 写入的现场验收。不能据此声称全课程准确率、CER／WER 或引用语义支持率达到某个百分比。具体证据和失败案例见验收文档。

隔离页最终迁到端口 8898，因为 8878 被另一个应用占用；其进程未被修改或停止。早期验收日志中的 8878 指当时的 QwenASR 隔离服务。

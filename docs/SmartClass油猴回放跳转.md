# 南邮 Smart Class 油猴回放跳转

课程列表、录音库“上半节回放”“下半节回放”和转写时间下方的“跳转”都只打开一个新标签页。入口不显示中转卡片，油猴脚本在这个标签页内检查浏览器登录、完成认证、打开对应视频片段并定位时间；成功后直接停留在学校播放器，原笔记或课程列表不动。

两节课合并后的时间使用实际下载长度换算，进入下半节时会减去上半节的真实时长；同一节课有多个媒体片段时，先选择正确片段，再设置片段内时间。

## 安装或更新到 1.2.0

1. 使用已有的篡改猴（Tampermonkey）。
2. 打开本机安装地址：`http://127.0.0.1:8765/course/replay-script.user.js`。
3. 在篡改猴的脚本预览中点击“安装”或“更新”，随后重新点击回放入口。旧版 1.0.1 会额外打开一个标签页，因此必须更新一次。

如果浏览器只显示源码，可在回放跳转页点击“复制脚本”，在篡改猴中创建新脚本、粘贴后保存。脚本源文件是 `static/userscripts/smartclass-replay.user.js`，无须加载已解压的扩展或查找 manifest.json。

## 登录与权限

- 账号和密码仍由原有本机课程服务保存；脚本不读取密码。
- 一次性登录票据交给浏览器使用，不在 Python 服务里提前消费；已登录的浏览器直接打开回放。未登录时，同一标签页短暂返回不可见的本机入口取得票据，然后直接进入学校页面。
- 脚本只匹配本机 `/course/replay` 和 `njupt.smartclass.cn`。直接打开学校平台时也会检查登录；未登录会用已保存的本机账号完成认证，再回到原来的学校页面。已经登录的普通标签页保持原页面。
- 没有第三方依赖、远程代码或跨站 HTTP 请求权限。登录接口由本机跳转页调用。
- 不用伪造观看心跳定位。任务只存放在油猴的标签页数据里，完成、失败时清除，关闭标签页后随之消失；不使用全局任务存储或跨标签页监听器。
- 正常跳转不展示中转页面。只有需要安装/更新脚本、配置账号或发生错误时显示处理入口；学校页面上的失败会直接弹出提示。

自动登录需要 QwenASR 本机服务正在运行并已保存账号；脚本默认连接 `http://127.0.0.1:8765`，自定义端口时需修改脚本中的 `LOCAL`。验证码、账号无效或认证失败时停止重试并显示处理入口。

回放页打开及重新回到页面时会核验学校会话并更新课程目录。课程目录结合教学班和“与我相关”的本学期回放动态生成，包括没有主讲或教学班信息的课程；这项检查不会启动转写队列。

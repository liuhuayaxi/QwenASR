# 图文课后复习笔记与 Windows 课堂省电模式

设置 → 推理位置 → 启用课堂省电模式 → 保存。新音频从下一段开始使用保存的配置；已经提交的音频继续使用原快照和回执。仅 Windows 表示远端不可用时不会启动 Mac ASR、向量或重排模型。

Windows 的 GPU 用于 CUDA BF16 ASR。默认 Qwen3 Embedding 0.6B 在 Windows CPU 上计算文档和查询向量，避免在 8 GB 显存中同时驻留多个 GPU 模型；相似度检索也在 Windows。Mac 保留录音、音频预处理、词法检索、来源元数据和网页。已有兼容向量按课程和版本增量复制，不要求重算整库。

当前节点实际运行在 Windows 主机的 Ubuntu-24.04 WSL 中。课程回放导入中不超过 90 秒的短片段也复用课堂常驻 ASR 模型，避免每个约一分钟的片段都重新创建进程、加载权重和释放显存。已有文件作业收据继续恢复原作业；超过课堂音频上限的片段保留文件协议。课堂协议通过能力接口声明生成上限，支持已保存的 128–8192 token 参数；旧节点不会把 4096/8192 静默缩成 2048，而是继续使用原文件协议，待节点升级后再使用常驻模型。

两个课程任务与自动索引共享一个课堂计算入口，达到短暂排队预算时使用同一操作编号有限重试；丢失响应也查询同一缓存结果，不另建重复 ASR 或向量批次。非暂时性参数、模型或令牌截断错误立即报告。课程页面分别显示已完成片段的模型加载、纯推理与排队累计；没有测量的时间显示“未记录”，常驻 worker 的总耗时不会冒充纯推理时间。整体任务还可能包含下载、AI 校对和笔记生成，不能用某一项累计时间当作整体耗时。

服务重启后，课程列表保留原始导入标识和分段协议标识，从原分段检查点继续，不会误走普通文件录音的继续入口。录音库的构造和只读查询不再把其他进程正在处理的录音标成中断；中断恢复只由实际服务启动时执行，并在整个服务运行期持有录音所有权锁，重复服务在改写任务前被拒绝。首次升级该锁时须等当前用户任务结束，再按正常方式安全重启，不能另外启动一个端口进行并行验证。

课堂会话每 20 秒续约一次，当前节点预约 90 秒；已经开始的 GPU 后台任务会先安全结束，后续后台任务等待课堂。课堂 ASR 在会话内复用模型，空闲和会话结束后释放。已运行的旧 MinerU 任务暂不能中途抢占。Windows CPU 向量不占 GPU 队列，在线请求等待有上限。

断网时录音继续写入本地，片段和配置先持久化。服务会重试待补转片段；进程恢复后也会继续，按原片段 ID 写回，防止重复追加。任务中心支持暂停或取消后续补转，音频保留。恢复原任务使用其原网络配置；修改全局配置不改变已经接受的操作身份。

笔记页的“生成课后复习笔记”会建立本节资料包，覆盖整节转写，读取同课程原件和早于本节的历史转写。匹配不足时用“补选本节课件”限定范围；恢复自动匹配可取消限制。旧索引是否完成不会阻止笔记直接读取原件。历史缺失或只检索到部分历史时，首次引入的判断范围必须说明。

光电子学每次整理先读取原 PPT 的学习要求页，包含章首、节首和要求汇总页。“掌握”完整覆盖本节涉及的概念、条件、必要公式和计算；“理解”解释概念与关系；“了解”只作简短说明，不展开独立公式、推导、计算题或必背清单。光波限制因子可以作为阈值增益公式的必要参数定义，但不会因此展开它的积分式。学习要求绑定原件版本，课件变更后重新核对；未到本课的后续要求不冒充本节讲授。生成、选图、修订和独立审查使用相同范围。以前未经范围核对的笔记保留原文，重新生成范围修订候选后再采用。

AI 设置始终复用服务端保存的对应功能配置。旧格式中的明确接口和模型可兼容读取；只保存一个功能时保留其他功能及凭据。空模型保存会被拒绝；逐句、摘要和问答不会互相借用不同模型来掩盖配置缺失。

录音工作台的“丢弃录音”需要连续两次确认，取消任一次都不会提交丢弃请求。最终确认后先停止收音，再安全收尾本条录音已开始的转写和音频写入，最后移入废纸篓；不影响其他录音。正在生成 AAC 时也能请求丢弃。浏览器断线或刷新后继续核对原录音的丢弃结果，状态记录和恢复清单随数据保留。这个功能不永久删除文件，也不会自动丢弃任何已有录音。

从废纸篓恢复整个录音目录到原位置后，刷新资料库即可继续处理。恢复必须与该次丢弃的录音、原位置和恢复清单一致；仅复制一份目录不会解除旧状态。每次丢弃和恢复保留独立历史，旧录音页面的迟到消息不能操作下一条录音。

普通 PDF 使用原生文本。扫描课件可复用已有、与原件哈希及原页码对应的 OCR 层来定位；图像、公式和布局以原页面为依据。新的笔记路径不自动运行 MinerU。PPTX 的原始幻灯片可以用 LibreOffice 渲染，不能用转写排版 PDF 冒充原图。

AGY 使用单独的资料会话。程序校验模型返回的来源、页码及归一化裁切区域，抽图后再让模型实际看图。裁切不全时扩展到整页复查；装饰和纯文字页不为凑数插图，排除理由保留。普通文本调用的工具限制保持不变。资料会话受 macOS 文件沙箱和执行限制约束，允许本任务目录及必要 CLI 状态和系统运行库，不使用跳过权限参数。

默认下载为 PDF。内部 Markdown、图片和来源信息保留在录音目录的 `.review-notes/<版本>/`，每个版本包含资料、覆盖清单、图片来源和哈希、写作草稿、候选 PDF、页面图及独立审查回执。网页解析受控图片接口，相对资产路径随版本历史保留。

新的课后笔记不设独立封面或目录，从正文直接开始，按概念、原课件图、公式条件与例题组织。PPT 的结构图、能带图、光路和曲线保留出处、图注与读图说明，贴近相关讲解。新的课后笔记直接生成 LaTeX 排版源稿，由固定中文教材模板和 XeLaTeX 编译 PDF。网页可编辑内容继续保留，PDF 使用独立的 LaTeX 源稿，避免网页长表和图注的分页限制。数学、原课件图、图注和真实课堂引用一起排版；了解项仍受同一学习深度检查。固定模板不接受模型自定义导言区或文件操作，编译关闭 shell 执行并限制资料路径。源稿、模板、字体、工具链、原件和图片共同决定缓存身份；编辑正文使旧源稿和审查失效。旧 Chromium 版本仍保留供历史追溯。编译组件缺失会明确报告，不悄悄回退为 Markdown 下载。

每个候选 PDF 必须逐页审查。每个审查会话为新会话，实际读取页面图，并按批次读取相关原图；每批最多四张图。审查结果绑定 PDF SHA-256、会话身份和实际页码。最多两轮自动修订，未解决的阻断问题保留为待处理。已完成的同版本审查批次可恢复，另一版本的通过结果不能复用。

生成期间人工编辑会保留；已存在人工编辑的正文也不会自动被生成结果覆盖。新成果保存为候选版本，在笔记页“查看新候选版本”中预览。采用时检查原正文是否仍与预览一致，通过的候选版本才能采用；原编辑进入版本历史。

新 PDF 导出需要本机 XeLaTeX 与 xdvipdfmx，以及固定模板所需的中文字体和 TeX 宏包。历史 Chromium 导出组件仍可通过 `npm ci --prefix scripts/note-export` 准备，并安装 Chromium 或使用本机 Google Chrome；`QWEN_ASR_NODE_MODULES` 和 `QWEN_ASR_CHROMIUM` 可指定历史导出运行时。缺少组件会明确报错，不产生空文件。

Windows 复用现有网关的认证和内网入口，增加 `/v1/capabilities`、`/v1/classroom/*` 和 `/v1/vectors/*`。部署前先确认没有活动作业及课堂预约，再由现有服务管理器安全停止网关；`scripts/deploy_classroom_extension.py` 会取得网关生存期锁后才进行安装，在线网关持锁时拒绝改动。它对协议 1 节点执行增量安装，使用 SQLite 一致性备份并备份原服务代码和配置，再增加扩展。完成后由服务管理器启动网关。不要用仓库的新网关直接覆盖旧节点及其运行配置。

模型准备是部署动作，不能由课堂查询触发。在节点源码目录显式运行 `venvs/asr/bin/python scripts/prepare_knowledge.py --model Qwen/Qwen3-Embedding-0.6B`。重排可按同一方式显式准备 Qwen3 Reranker 4B，再在知识设置中启用；未准备时明确保留排名融合。模型 revision、tokenizer、维度、池化、归一化、查询指令、最大长度及精度必须一致，契约变化使用另一索引版本。节点只加载本地已准备文件。

回滚前先保留当前新增录音、笔记、配置和回执。Mac 代码可恢复到本次改动前的 Git 提交，配置使用本机受保护备份恢复，或者在设置中明确关闭省电模式并选择所需位置。不能用整个旧数据库覆盖后来产生的学习资料。

Windows 在没有活动作业、课堂会话结束后停止服务，恢复部署备份中的 `server/`、`workers/` 和需要回滚的配置，再启动现有服务。保留当前 `data/`、向量副本、认证文件及任务回执；源码回滚不要求回滚或清空作业数据库。恢复旧节点时，Mac 应同时恢复兼容版本或明确选择本机模式。

本次验收结果与最终 LaTeX 成品位于项目 `output/learning-scope-20261015/delivery/`，本轮说明位于 `output/learning-scope-20261015/验收说明.md`；早期 Windows 回放与隔离链路验收保留在 `output/illustrated-notes/`。这些目录可能包含私人课件和课堂内容，不加入 Git。接口、隔离测试、真实 Windows 请求和成品逐页审查分别记录，不能互相替代。

长课的 LaTeX 源稿按真实知识清单分批编写，每批最多十个知识点。批次保留完整参考正文和全课知识提纲，只传入本批实际相关的转写、原图和相邻课件页，并记录包含及排除的证据清单。通过批次有独立检查点，中断后不重写已通过内容；三份完整无效提案后停止，连接中断或取消不冒充一份已完成提案。最终仍须完整核对知识 ID、引用、配图及独立写作者身份，不能以分批为由遗漏后半节。

程序会把普通字面代码转换为受控的转义文本，并为缺少标题参数的教材框补充固定标题；不开放任意宏、文件读取或 shell 执行。不同 PDF 的完整逐页审查串行，同一 PDF 内最多两个审查批次。编译器适配更新后，只有实际 PDF 字节、源文、图片、工具链、范围政策和完整审查页码均相同时，才可复用同版本的审查报告；不同内容的候选仍须重新审查。

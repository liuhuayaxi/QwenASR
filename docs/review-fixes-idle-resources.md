## 空闲资源策略

- **本地模型：** 没有排队或执行中的推理任务时，保持页面连接最多空闲 30 秒，无页面连接时 5 秒，随后退出模型子进程。下次转写自动重新加载。暂停超过保温窗口后，首段会增加模型加载等待。
- **录音列表：** 保存有界的列表字段缓存，文件路径、inode、修改时间、状态时间或大小变化时失效；不把完整正文和转写保留在这个缓存里。
- **任务与速记后台：** 无变化的任务摘要复用缓存；15 秒重试检查只读取任务头，仅在任务到期时载入完整录音。活动作业绕过空闲摘要缓存。
- **浏览器：** 页面隐藏时暂停状态读取和绘制，录音音频仍继续发送；空闲页面每 60 秒兜底检查，活动状态使用较短间隔，切回页面立即检查。相同数据避免重复修改 DOM，音量表复用缓冲并限制绘制频率。
- **macOS 内存观测：** 使用原生 `libproc` 获取 RSS，避免每次健康检查创建 `ps` 子进程。
- **远程网关：** 新任务唤醒调度器，空队列每 5 秒兜底检查；宿主与 GPU 展示探针短时缓存，任务准入和模型释放验证仍读取新观测。

列表缓存的 4 MiB、任务头缓存的 2 MiB 上限按序列化内容计量，不代表整个 Python 进程的 RSS 上限。

## 可重复的合成对照

后端对照生成 40 条录音，每条 300 个片段及长笔记；每轮连续执行 5 次真实列表与任务摘要读取。两侧使用同一脚本和参数，启用 `tracemalloc`，不加载 ASR 模型。

| 预热后指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 完整录音载入次数 | 1,140 | 0 |
| 该轮进程 CPU 时间 | 10.9030 秒 | 0.2259 秒 |
| 该轮 Python 分配峰值 | 4,996,449 字节 | 189,317 字节 |

冷轮完整载入从 1,144 次降到 120 次，CPU 时间从 10.3767 秒降到 1.6411 秒。这里测量的是指定 API 工作负载，不是用户 Mac 的整机 CPU 百分比或真实模型内存。

真实 Chromium、合成已完成课堂页面的对照：可见静置 31 秒，纳入统计的状态轮询请求从 22 次降为 0，DOM 变更从 188 次降为 0；模拟隐藏 16 秒，轮询请求从 4 次降为 0，DOM 变更从 66 次降为 0。采样窗口从初始加载完成后开始，低频校验仍保留。隐藏状态使用可控的可见性事件模拟，合成 SSE 结束造成的重连不计入对比。

复跑当前版本的后端合成基准：

```bash
.venv/bin/python scripts/benchmark_idle.py
```

用同一脚本对比另一个版本的源码目录：

```bash
.venv/bin/python scripts/benchmark_idle.py --source /path/to/baseline
```

该脚本使用临时数据，不读取用户的实际录音和笔记。

## Mac 上机验收

先用 `stop_qwen_asr.command` 正常停止旧服务，再切换到 PR 分支，用 `start_qwen_asr.command` 启动并重新加载页面。存在未完成录音或任务时，先在页面暂停或完成相关操作。

1. **空闲与恢复。** 录制并转写一小段后暂停收音，保留页面打开，等待所有后台工作结束。在项目目录运行下面的采样命令。超过 30 秒空闲后应看到 `local_model_loaded=false`、`asr_worker_pid=null`；再次恢复转写应自动启动模型并正常出字。

   ```bash
   python3 scripts/sample_idle_resources.py --seconds 60
   ```

   自定义服务端口时加 `--port 端口号`。`average_workbench_cpu_percent` 是工作台主进程在采样区间内的平均 CPU，按一个 CPU 核计；主进程和 ASR 子进程 RSS 分开列出。采样期间服务重启会使 CPU 平均值为空。活动监视器中的浏览器进程需要另行观察。

2. **后台页面。** 录音中切到其他标签页，等待后切回，确认音频和文字持续保存；暂停录音后再次隐藏页面，观察 CPU 回落。
3. **慢网络编辑。** 保存速记后立即继续输入，或切换课堂再输入；新草稿应保留。内联修改遇到保存失败后，应仍能继续编辑和重试。
4. **续跑与课程归属。** 对包含静音的课程转写暂停、继续，核对此前文字保留；移动或合并已索引课程后，在目标课程检索，旧课程不再命中迁走的片段。
5. **远程策略。** 优先远程模式在首次提交前断线时可本地回退；强制远程保留待补转。对已有提交收据的请求，重试复用原操作，不应自动改成本地重算。

WSL 安装步骤和模型清单验收见 [推理节点说明](../ai-infer-node/README.md)。真实 MLX/CUDA 模型、macOS 原生 RSS 与 WSL cgroup 委派需要在对应硬件上验收。

## 剩余的活动成本

文件系统监听是进程级单实例，SSE 保活不扫描录音库。真实 watcher 对照中，100 个进程内连接空闲约 15 秒，没有一次完整录音读取。外部同步或文件编辑持续改变课程目录时，仍会触发录音发现与刷新；这种活动不属于无文件变化的空闲基准。
